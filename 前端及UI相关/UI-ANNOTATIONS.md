## 0. 三条硬规则（先读）

1. **emoji 不是文案。** 下文所有 `🌐 📊 💬 🔔 👤 🛠 🔒 ⎋ 📚 🏢 🛰️ 💎 ⚙️ 🐳 🤖 🇺🇸 ▾ ›` 等，是把画布里的**图标占位**读出来的字符。实现时：
   - 图标位一律替换为 **16×16 SVG，stroke 1.6–1.9，currentColor**（`react/src/icons.tsx` 已内置）；
   - 纯装饰性 emoji 直接删除；
   - 国旗 `🇺🇸 🇬🇧` 是语言选择器的语言标识，可保留为国旗/语言标签，也可用 `English` 文字替代。
2. **绿色永久禁用。** 全站不存在绿色。正向/活跃态 = 白色 `#E7E9EA`；警示 = `#D29922`；危险 = `#E5484D`。
3. **字号/颜色用 token 名**，不要写死像素色值（见 §1）。
