能言 · 划词翻译插件 安装说明
============================

版本以本目录 manifest.json 的 "version" 为准（打包脚本 scripts/build_extension.sh 只读它，
不再另记一份版本号，避免出现两处版本互相打脸）。

一、拿到安装包
--------------
- 站点直下：https://<你的站点>/extensions/langcross-extension-latest.zip
  同目录另有带版本号的固定包 langcross-extension-<version>.zip，便于内部留存与回溯。
- 自托管方本地打包：scripts/build_extension.sh
  改动 extension/ 下任何文件后必须重跑，否则 build_extension.sh --check
  与前端 vitest 的「交付漂移锁」会红灯（防的就是「改了源码忘了重打包，站点还在发旧包」）。

二、安装（Chrome / Edge / 360 等 Chromium 内核通用）
--------------------------------------------------
1. 解压本 zip 到一个**固定目录**（别删——浏览器是从该目录直接加载扩展的）。
2. 地址栏打开 chrome://extensions（Edge 为 edge://extensions）。
3. 右上角开启「开发者模式」。
4. 点「加载已解压的扩展程序」，选中第 1 步的目录。
5. 工具栏出现「能言设置」图标即安装完成。

为什么走「加载已解压」而不是上架商店：本插件面向企业内网与私有化客户，
商店审核与这类常驻内网域名不匹配。当前**没有**应用商店渠道，
对外口径请说「下载 zip 本地加载」，不要声称可在商店搜索安装。

三、配置
--------
点工具栏图标，填完保存：
  服务地址   你的能言站点根地址，如 https://langcross.example.com（不用带 /openapi 后缀）
  API Key    在站点「管理后台 → 开放 API → API Key」签发的 tk_... 开头的密钥
  目标语言   逗号分隔的语言码，如 en,ja（zh 为简体中文）
  翻译模式   快速＝秒级、不查知识库；专业＝带校对与术语库，计费更高

四、使用
--------
网页中选中一段文字 → 选区旁浮出「译」按钮 → 点击后在气泡里看结果，可一键复制。

五、常见问题
------------
- 浮出按钮不出现：扩展缺少接口地址的访问权限。首次保存时浏览器会问「允许读取所有网站数据」，
  若拒绝了，去 chrome://extensions → 本扩展「详情」→ 网站访问权限 → 改成「在所有网站上」。
- 返回 401 / 鉴权失败：API Key 已被吊销，或该租户积分不足（积分口径见站点「用量」页）。
- 内网无法访问外网商店：正是本包的适用场景，按第二节加载即可。
- 升级：用新 zip 覆盖解压到同一目录，回 chrome://extensions 点扩展卡片上的「刷新」按钮。
