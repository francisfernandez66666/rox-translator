# 发布前客户级 E2E UAT · 用例集（字节级预期 + 实测结论）

- 被测对象：`https://langcross.lexicorn.cn`（生产站）
- 执行日期：2026-09-25；测试租户 `uat_eco_01`（tenant_id=3，user_id=10009，组织「UAT测试电商 / UAT Test Ecommerce」，行业电商，角色运营）
- 录制方式：页面内 fetch 包装器记录每次请求的 method/path/请求体/状态码/响应体前缀 + 真实浏览器点击
- 判定口径：PASS=行为与预期字节一致；FAIL=缺陷，编号见《缺陷清单.md》
- 纪律：止步于真实付款——全程未点「我已付费」、未发生任何真实资金转移
