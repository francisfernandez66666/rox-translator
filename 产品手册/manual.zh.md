## 一、产品概览

**能言（LangCross）** 是面向企业与团队的 AI 翻译协作平台，把三类翻译方式和一个企业语料资产体系整合在一起：

| 能力 | 说明 |
|------|------|
| 即时翻译 | 对话框式文本翻译，输入即译，支持一次翻往多个目标语言 |
| 翻译工单 | 上传 docx / pptx / xlsx / pdf 等文件，走「建单 → 审批 → 翻译 → 交付」完整流程，按原格式交付译文文件 |
| 对照编辑 | 原文/译文双栏逐段对照，可修改、通过、驳回并留批注 |
| 知识库 / 翻译记忆（KB/TM） | 企业术语、双语句对、品牌固定译名进入知识库，翻译时自动命中并统一口径 |

主要特点：

- **40+ 语言互译**，界面本身提供 12 种语言（简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Русский、العربية、ไทย），阿拉伯语界面为从右到左排版。
- **双翻译模式**：「快速」轻量高效；「专业校对」带知识库术语校准、质量评估与硬性校验闸门，适合对外发布内容。
- **企业隔离**：每个租户的数据、知识库、成员相互隔离；组织内再按部门隔离知识库与预算。
- **多端一致**：除网页端外，提供浏览器划词扩展、Word 加载项、VS Code 插件和开放 API/SDK，译文口径与网页端同源。

## 二、快速上手

### 2.1 登录

打开企业分配给你的访问地址（平台地址或企业专属子域名），在登录页输入**用户名**和**密码**即可。

- 忘记密码：点击「找回密码」，通过绑定邮箱接收验证码重置。
- 企业已启用统一身份（SSO）时，登录页会出现「或使用企业身份源登录」按钮，点击后用企业账号直接登录。
- 首次登录：若管理员为你开通账号时未设置邮箱，系统会弹出不可关闭的「请绑定邮箱」窗口，请先完成绑定；批量开通的账号首次登录会被要求「首次登录请修改密码」。

### 2.2 注册 / 加入企业

两种进入方式：

- **加入已有企业**：注册时填写组织编码 + **邀请码**（必填，向贵企业管理员索取），即加入对应部门，成为普通用户。通过企业专属子域名（`企业编码.域名`）访问注册页时，企业信息会自动带入，此入口只能注册为该企业普通成员。
- **创建新企业**：邀请码留空注册即创建新组织，注册人成为该组织的组织管理员，可继续邀请同事加入（见第九章）。

注册流程支持 AI 助理引导：选择账号类型（个人/企业）、企业身份（管理员建企业 / 成员凭邀请码加入）、行业与职业角色、填写账号信息，按提示逐步完成即可，支持返回上一步。选择「个人」即开通个人版，功能边界见 [3.1 个人版用户](#31-个人版用户)。

### 2.3 认识界面

登录后进入工作台，主要区域：

| 区域 | 内容 |
|------|------|
| 顶栏 | 三个工作台页签：**即时翻译**、**翻译工单**、**对照编辑**；右侧为积分余额徽标、通知铃铛、语言切换、账号菜单；部门管理员及以上额外可见「上传知识库」按钮与「进入管理后台」入口 |
| 「更多」抽屉 | 我的账号等自助页入口与页脚 |
| 主内容区 | 当前页签的工作界面 |
| 右下「AI 助手」 | 随时可唤起的智能助理挂件（见第十一章） |

- **切换界面语言**：顶栏语言下拉，选项各以本语言自称（如「日本語」「한국어」）；选择后全站立即生效，浏览器首次访问会自动按系统语言检测。
- **移动端**：手机/平板浏览器可直接使用，窄屏下后台侧栏自动转为抽屉菜单。
- **账号菜单**（右上角头像）：进入管理后台（部门管理员及以上）/ 返回工作台、修改密码、修改邮箱、我的职业角色、退出登录。

### 2.4 完成第一次翻译

1. 在「即时翻译」输入框粘贴要翻译的文本；
2. 确认源语言（默认「自动检测」），点目标语言选择器选好一种或多种语言（候选按「知识库语言 / 其他语言」分组）；
3. 选择模式（快速 / 专业校对），点击「翻译」；
4. 译文以对话气泡形式逐段上屏，可复制译文、查看原文、继续追问修改风格。

文件翻译请看第五章。

## 三、角色与权限

租户内共三级角色，权限逐级扩大：

| 角色 | 谁能用 | 可见功能 |
|------|--------|----------|
| **普通用户** | 所有成员 | 即时翻译、翻译工单（建单/查看/下载）、对照编辑、通知中心、AI 助手、我的账号；界面语言、职业角色设置 |
| **部门管理员** | 由组织管理员指定 | 普通用户全部功能 + 管理后台基础菜单：**总览**（含用量明细）、**反馈/审批**（审批工单、回复反馈）、**知识库**（本部门包/跨部门包）、顶栏「上传知识库」 |
| **组织管理员** | 每企业至少一名（创建者或被授权人） | 部门管理员全部功能 + **组织与成员**（部门树、成员、邀请码、预算）、**外部调用**（API Key、Webhook、SDK）、**知识库**（组织包/部门包/跨部门包全类型）、品牌名（固定译名）维护、SCIM 组织同步配置 |

说明：

- 本手册只覆盖上述租户内角色；平台运营功能不在范围内。
- 「反馈/审批」页签中带有「记忆审核」「完成反馈归档」等字样的操作属于平台侧流程，租户界面不出现，无需关注。
- 权限疑问请联系贵企业的组织管理员。

### 3.1 个人版用户

注册时选择「个人」账号类型（不需要组织编码和邀请码），即开通**个人版**——顶栏身份徽标显示「个人版」，账号归你自己管理，没有企业成员与部门概念。

个人版可用的功能：

| 功能 | 说明 |
|------|------|
| 三大工作台 | 即时翻译、翻译工单、对照编辑，与企业版完全一致 |
| 管理后台 | 顶栏账号菜单可进入：**知识库**（上传维护自己的术语表，仅自己可见可用）、**外部调用**（自助签发 API Key，配套浏览器扩展/Word 加载项/SDK 使用）、**总览**（自己的用量明细） |
| 我的职业角色 | 同企业版，按岗位自动装配角色包（见 7.5） |
| 自助页 | 更多 → 我的账号；修改密码、修改邮箱、通知中心、注销账号 |

与企业版的差异：

- **没有「组织与成员」**：不存在部门、成员开通、部门预算等管理需求；
- **工单没有审批环节**：创建的翻译工单直接进入排队执行，不会停在「待审批」；
- 没有企业专属子域名和组织共享知识库；行业包、语言文化包等平台通用知识库照常自动生效。

个人版额度或余额不足时，按界面提示处理即可。

## 四、即时翻译（工作台）

「即时翻译」是登录后的默认页，一张整屏对话框，历史在上、输入贴底。

### 4.1 输入区（框脚工具条）

一张输入卡，内含单行自适应输入框和一行工具条：

| 控件 | 说明 |
|------|------|
| 原文·自动检测 | 选择源语言，默认自动检测 |
| 目标语言 | 点开选择器；语种按「知识库语言 / 其他语言（AI翻译）」分组，「更多语言…」可搜索全部语种；已选语种以标签显示，超过 3 个折叠为「+n」，点开可逐个移除 |
| 专业校对 / 快速 | 翻译模式。快速＝AI 初翻+校对，轻量高吞吐；专业校对＝知识库术语校准 + 质量评估 + 硬性校验闸门全流程，适合正式发布内容 |
| 缩翻 | 勾选后译文按长度约束收敛，适合标题、按钮文字等有字数限制的场景 |
| 翻译（主按钮） | 开始翻译；生成中可点「停止生成」 |

预估消耗会在发送前显示。余额不足或额度用尽时界面会提示，并说明联系管理员处理。

### 4.2 对话与结果

- 原文与译文在同一气泡框内上下呈现，译文流式逐段上屏。
- 每条译文标注来源方式：**精确命中 / 模糊匹配 / 语义相似**（来自知识库）或 **在线翻译**（AI 生成）；命中知识库术语时高亮显示。
- 气泡操作：复制译文、查看原文；可继续发送指令让 AI 调整语气、风格，上下文会延续。
- 翻译过程的环节（术语检索 → 机器翻译 → 术语校准 → 翻译完成）在界面上有阶段提示。

### 4.3 会话管理

对话框顶部提供：

- **搜索本会话消息**（快捷键 Ctrl/⌘+K）；
- **导出会话记录**（Markdown 文件）；
- **清空对话**。

### 4.4 用量显示

界面上的消耗量统一以「积分」显示，并折算「约可翻句数」。输入区附近常显：余额（积分 ≈ 句数）、今日消耗、部门预算进度（挂了部门且有预算时）。

## 五、翻译工单（文档翻译）

所有**文件翻译**都在「翻译工单」页发起，走完整流程：建单 → （按企业设置）审批 → 翻译 → 交付。

### 5.1 创建工单

点击「创建翻译工单」，选择「文本」或「文件」页签：

- **文本**：粘贴长文本，选目标语言与模式，直接建单。
- **文件**：上传一个或多个文件，可一次勾选多种目标语言（产物打包为 zip 下载）。

关键字段：

| 字段 | 说明 |
|------|------|
| 交付方式 | **还原文件模式**（默认）：按原格式交付译文文件（版式还原），另附纯文案 .md 兜底产物；**纯文案模式**：本地提取正文翻译，交付译文 .md，不承诺版式（适合老格式 doc/ppt/xls、odt/epub/rtf 等） |
| 模式 | 快速（无知识库）/ 专业校对 |
| 目标语言 | 可多选 |
| 预计消耗 | 建单前显示「预计消耗 {n} 句 · 余额 {n} 句」 |

文件格式支持：

| 类别 | 格式 | 交付 |
|------|------|------|
| 可还原版式 | docx、pptx、xlsx、pdf、txt、csv、md | 同格式译文文件 |
| 对照表交付 | srt、vtt、json、yaml 等 | 原文/译文对照 xlsx |
| 仅纯文案 | doc、ppt、xls 系老格式、odt/ods/odp、rtf、epub | 译文 .md |

限制与说明：

- 单次工单文件数量与大小有上限；PDF 超过 40MB 或 120 页会友好拒绝并提示先转为 docx。
- 扫描版 PDF（纯图片）不支持；图片内的文字按产品策略不翻译。
- 版式回写万一失败，该文件自动降级为 .md 交付并站内信通知，不会整单失败。

### 5.2 工单状态与流转

「我的工单」列表可按状态筛选，状态含义：

```
排队中 → 翻译中 → 已完成
待审批 → 已批准 → 翻译中 …    （企业开启审批时）
        └→ 已驳回
任意进行中状态 → 已取消
```

- 进行中可点「取消」；已结束的可「删除」。
- 若贵企业开启了审批，工单先落在「待审批」，由部门管理员/组织管理员在后台「反馈/审批」的审批台批准（已批准）或驳回（已驳回，附原因）。

### 5.3 查看进度与下载

点开工单看「执行进度」步骤条，环节包括：解析提取 → 知识库匹配 → AI 初翻 → 专业校对 → 硬闸校验 → 文化检查 → 回写文件 等（按模式与文件类型显示）。

- 完成后点「下载」取译文；纯文案兜底可用「仅下载译文文案（.md）」。
- 多语言/多文件任务下载即为 zip 包。

### 5.4 质检报告

专业校对模式的已完成工单带有「质检报告」区块：整体结论（质检通过 / 质检未通过 / 质检存疑）、机器评估分（满分 100）及分段说明。对结果有异议可在工单详情「提交意见反馈」，管理员会在后台看到并回复。

### 5.5 对照编辑衔接

已完成工单可一键进入「对照编辑」逐段复核，见下一章。

## 六、对照编辑

「对照编辑」用于对工单译文做人工终审：

1. 从工单详情跳转，或在「对照编辑」页按工单 ID/工单号「加载」；
2. 左栏原文、右栏译文逐段对照，知识库术语在原文侧高亮；
3. 每段可：**通过** / **驳回**（填写批注/驳回原因）/ 直接修改译文；
4. 点「保存」留存人工修订。

人工确认的高质量句对是翻译记忆的优质来源——企业知识库管理员可将其整理导入（见第七章）。

## 七、知识库与翻译记忆

知识库（KB）让翻译「懂你的企业」：统一术语、复用已确认译文、锁死合规表述。

### 7.1 四层内容

| 层 | 内容 | 典型用途 |
|----|------|----------|
| L1 术语 | 术语对照（含品牌名、产品名固定译法） | 强制统一用词 |
| L2 翻译记忆（TM） | 已确认的原文/译文句对 | 整句或片段直接复用 |
| L3 安全句 | 禁用词 / 替换对 / 风格规范 | 语言文化硬闸校验，译文中自动拦截或替换 |
| L4 碎片 | 零散表达、句式参考 | 模糊匹配的例句参考 |

翻译时的命中优先级：本组织链上的部门包（本部门→上级→根，就近覆盖）＞ 组织包 ＞ 行业/语言文化包；跨部门共享包需管理员开启后作为回退层参与。

### 7.2 谁可以维护什么

| 操作 | 所需角色 |
|------|----------|
| 顶栏「上传知识库」（识别文件 → 选包 → 导入） | 部门管理员及以上 |
| 创建/维护**部门包**、**跨部门包** | 部门管理员及以上 |
| 创建/维护**组织包（本企业）**、跨部门共享总开关、包级授权 | 组织管理员 |
| 维护「品牌名」（品牌/产品固定译名） | 可访问知识库面板的角色 |
| 导入双语语料 / TMX、导出 TMX | 部门管理员及以上 |
| 维护「语言文化规范（安全句）」 | 部门管理员及以上 |

### 7.3 包类型

- **组织包（本企业）**：全企业生效；
- **部门包（本部门）**：仅本部门及组织链内可见，实现部门级术语隔离；
- **跨部门包（共享）**：默认不外借，包级「跨部门共享·开/关」+ 企业策略开关共同决定是否对其他部门生效。

### 7.4 导入方式

进入管理后台「知识库」面板（部门管理员及以上）：

- **文件导入**：上传术语表/文档，系统识别后写入所选包；
- **双语语料 / TMX 导入**：批量写入翻译记忆，兼容主流 CAT 工具（Trados/memoQ 等）导出的 TMX；
- **导出 TMX**：把企业记忆带回原有工具链。

平台侧还会按行业自动装配通用「行业包 / 语言文化包」，无需企业维护，翻译时自动生效。

### 7.5 我的职业角色（全员）

账号菜单 →「我的职业角色」：从预置角色词典（15+ 职业）中选择自己的岗位角色。翻译时系统自动装配对应角色包，让术语与语气更贴近你的工作场景。

## 八、账户与个人设置

入口：顶栏右上角账号菜单，及「更多」抽屉中的自助页。

| 项目 | 路径 | 说明 |
|------|------|------|

## 九、组织与成员管理（组织管理员）

入口：账号菜单 →「进入管理后台」→ 左侧「组织与成员」。

### 9.1 组织结构

- **新建组织 / 新建部门**：维护企业多级组织树；支持重命名。
- **部门预算**：为部门「分配月度预算」，控制该部门成员的翻译用量；成员的界面会显示部门预算进度。

### 9.2 成员账户

「成员账户」页管理企业全部账号：

- **开通用户**：单个创建成员，指定角色（普通用户 / 部门管理员 / 组织管理员）与所属组织；
- **Excel 批量导入用户**：一次开通多名成员，初始密码经邮件通知，成员首次登录被要求修改密码；
- 对已有成员：**重置密码**、**启用/停用**账号、调整角色与组织归属。

### 9.3 邀请员工

「邀请员工」页生成**邀请码**（可多个、可指定加入的组织层级）。把组织编码 + 邀请码告知同事，其在注册页填写即加入对应部门。

### 9.4 SCIM 组织同步（可选）

「更多 → 我的账号」中的 SCIM 卡：企业使用 Okta、Entra ID 等身份源时，可获取 SCIM 端点与令牌完成成员自动开通/同步；启用后员工可走登录页的 SSO 按钮免密登录。

## 十、外部调用与集成（组织管理员）

入口：管理后台 →「外部调用」。三个子页：**开放 API**、**回调通知**、**官方 SDK**。

### 10.1 开放 API Key

- **签发 API Key**：创建时明文完整显示**仅一次**，请立即保存；
- 支持对 Key **启用/停用、轮换、设置每日限额、删除**；
- Key 绑定本企业租户与积分口径，用 API 产生的消耗与网页端同账。

开放 API 提供：异步翻译任务（创建 → 轮询 → 下载，支持多文件多语言，产物可打包 zip）、同步短文翻译（≤5000 字符、≤5 语言）、余额与用量查询、知识库统计。接口文档可在浏览器访问站点的 `/openapi/docs` 查看。

### 10.2 Webhook 回调

登记回调 URL 并订阅事件（如 `translation.completed`），翻译完成时平台主动通知贵方系统；支持签名校验（X-Signature）、发送测试、查看投递历史与重试。

### 10.3 官方 SDK 与插件

「官方 SDK」页提供三端安装指引与下载入口：

| 端 | 获取方式 | 用途 |
|----|----------|------|
| Python | 本站「官方 SDK」页下载 `.whl`（或源码包 `.tar.gz`）后本地安装：`pip install <下载的文件>`（包由本站 `/sdk/` 托管，未发布外部注册表） | 程序化翻译、批量任务  |
| TypeScript | 本站「官方 SDK」页下载 `.tgz` 后本地安装：`npm install <下载的文件>`（同上，本站 `/sdk/` 托管） | Node/前端集成  |
| Java | Maven 源码分发 | 企业内系统对接 |
| 浏览器划词扩展 | 该页下载 zip（无应用商店渠道） | 任意网页选中文本→点浮出「译」按钮→气泡看译文并复制；快捷键 Alt+Shift+T（macOS 为 Alt+T） |
| Word 加载项 | 站点提供加载项清单，Word「插入 → 获取加载项 → 上传我的加载项」侧载 | 在 Word 内翻译选中文本并插回文档 |
| VS Code 插件 | 仓库内 vscode-extension | 编辑器内选中文本就地翻译、查术语 |

**扩展/加载项配置**（划词扩展 popup 与 Word 窗格相同逻辑）：填**服务地址**（站点根地址）、**API Key**（本章 10.1 签发）、**目标语言**、**翻译模式**（快速/专业）即可使用，术语与翻译记忆与站内一致。

⚠ 扩展升级后若样式未变：用新 zip 覆盖**同一目录**，并到 `chrome://extensions` 点该扩展卡片上的**刷新**按钮。

### 10.4 部门管理员的边界

部门管理员如需 API 集成，请联系组织管理员开通 Key；「外部调用」菜单不对部门管理员显示。

## 十二、常见问题

**Q1：翻译按钮点不动 / 提示额度不足？**
当前余额或部门预算已用完。普通用户请联系企业管理员处理；管理员可在管理后台查看用量明细。

**Q2：文件翻译入口在哪？聊天框怎么不能传附件了？**
文件翻译统一走「翻译工单 → 文件」，对话框只做纯文本翻译。

**Q3：PDF 翻译被拒绝？**
超过 40MB 或 120 页的 PDF 请先转为 docx 再建单；扫描版 PDF（整页图片）暂不支持。

**Q4：为什么译文和我的术语表不一致？**
检查术语是否已导入知识库且包对本部门可见（第七章）；正式内容请选用「专业校对」模式。

**Q5：交付的 docx 版式和原文有出入？**
「还原文件模式」绝大多数情况保持版式；个别复杂版式会降级为 .md 文案交付并站内信通知。可下载 .md 后用对照编辑复核，或提交反馈。

**Q6：刚翻译完，余额数字没变？**
计量在翻译完成瞬间同步落库，若页面未刷新请手动刷新一次；仍异常再提交反馈。

**Q7：换手机/平板能用吗？**
浏览器直接访问即可，界面自适应窄屏；扩展与加载项以桌面端为主。

**Q8：界面文字显示不全或排版怪（阿拉伯语等）？**
先切换其他语言确认是否为个别词条，然后通过反馈渠道提交截图。
