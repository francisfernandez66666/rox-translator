## 第1章 製品の概要

**LangCross（能言）** は企業・チーム向けの AI 翻訳コラボレーションプラットフォームです。3 種類の翻訳方式と 1 つの企業コーパス資産体系を統合しています：

| 機能 | 説明 |
|------|------|
| リアルタイム翻訳 | チャット形式のテキスト翻訳。入力しながら即翻訳、1 回で複数のターゲット言語へ翻訳可能 |
| 翻訳チケット | docx / pptx / xlsx / pdf などのファイルをアップロードし、「作成 → 承認 → 翻訳 → 納品」の完全なフローを実行、元のフォーマットのまま翻訳ファイルを納品 |
| 対照編集 | 原文／訳文を 2 画面に並べて段落単位で対照表示。修正、承認、却下とコメント残しが可能 |
| ナレッジベース / 翻訳メモリ（KB/TM） | 企業の用語、対訳ペア、ブランド固定訳をナレッジベースに登録し、翻訳時に自動ヒットして表記を統一 |

主な特徴：

- **40以上の言語間翻訳**、インターフェース自体は 12 言語に対応（简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Русский、العربية、ไทย）。アラビア語インターフェースは右から左へのレイアウト。
- **2 つの翻訳モード**：「高速」は軽量で高效率；「プロ校正」はナレッジベースの用語校正、品質評価、ハードチェックゲートまで揃ったフルフローで、社外公開コンテンツに適する。
- **企業間の隔離**：テナントごとにデータ・ナレッジベース・メンバーが相互に隔離。組織内ではさらに部門単位でナレッジベースと予算を隔離。
- **マルチ端末で一致**：Web のほかに、ブラウザの選択翻訳拡張機能、Word アドイン、VS Code 拡張、オープン API/SDK を提供し、訳文の表記は Web と同一ソース。

## 第2章 クイックスタート

### 2.1 ログイン

企業から割り当てられたアクセスアドレス（プラットフォームアドレスまたは企業専用サブドメイン）を開き、ログイン画面で**ユーザー名**と**パスワード**を入力するだけです。

- パスワードを忘れた場合：「パスワードをお忘れですか？」をクリックし、登録済みメールアドレスに届く確認コードでリセットします。
- 企業が単一ID連携（SSO）を有効にしている場合、ログイン画面に「または企業IDプロバイダーでログイン」ボタンが表示されます。クリックすると企業アカウントで直接ログインできます。
- 初回ログイン：管理者がアカウント作成時にメールアドレスを設定していなかった場合、閉じられない「メールアドレスを登録してください」ウィンドウが表示されますので、先に登録を完了してください。一括作成されたアカウントは初回ログイン時に「パスワード変更」を要求されます。

### 2.2 登録 / 企業への参加

参加方法は 2 つあります：

- **既存企業に参加**：登録時に組織コード + **招待コード**（必須。貴社の管理者にお求めください）を入力すると、対応する部門に一般ユーザーとして参加します。企業専用サブドメイン（`企業コード.ドメイン`）経由で登録画面にアクセスすると企業情報が自動反映され、この導線ではその企業の一般メンバーとしてのみ登録できます。
- **新規企業を作成**：招待コードを空欄で登録すると新しい組織が作成され、登録者がその組織の組織管理者になります。その後同僚を招待して参加させることができます（第9章を参照）。

登録フローは AI アシスタントのガイドに対応しています：アカウント種別（パーソナル／企業）の選択 → 企業での立場（管理者が企業を作成 / メンバーは招待コードで参加）→ 業種と職種の選択 → アカウント情報の入力、という案内を順に進めるだけで完了し、前のステップへ戻ることもできます。「パーソナル」を選ぶとパーソナル版が開始されます。機能の範囲は [3.1 パーソナル版のユーザー](#31-パーソナル版のユーザー) を参照してください。

### 2.3 インターフェースを知る

ログイン後はワークスペースに入ります。主な領域：

| 領域 | 内容 |
|------|------|
| トップバー | 3 つのワークスペースタブ：**リアルタイム翻訳**、**翻訳チケット**、**対照編集**；右側にポイント残高バッジ、通知ベル、言語切替、アカウントメニュー；部門管理者以上は「ナレッジベースをアップロード」ボタンと「管理コンソールへ」入口が追加表示 |
| 「その他」ドロワー | マイアカウントなどのセルフサービスページへの入口とフッター |
| メインコンテンツ領域 | 現在開いているタブの作業画面 |
| 右下の「AI アシスタント」 | いつでも呼び出せるスマートアシスタントウィジェット（第11章を参照） |

- **インターフェース言語の切替**：トップバーの言語ドロップダウン。各項目はその言語の表記で表示（例「日本語」「한국어」）；選択後全站に即時反映され、ブラウザ初回アクセス時はシステム言語が自動検出されます。
- **モバイル**：スマートフォン／タブレットのブラウザでもそのまま利用できます。狭い画面では管理画面のサイドバーが自動的にドロワーメニューへ切り替わります。
- **アカウントメニュー**（右上のアバター）：管理コンソールへ（部門管理者以上）/ ワークスペースに戻る、パスワード変更、メールアドレス変更、自分の職種、ログアウト。

### 2.4 最初の翻訳を完了する

1. 「リアルタイム翻訳」の入力欄に翻訳したいテキストを貼り付けます；
2. 原文言語（デフォルトは「自動検出」）を確認し、ターゲット言語ピッカーで 1 つ以上の言語を選択します（候補は「ナレッジベース言語 / その他の言語」にグループ化）；
3. モード（高速 / プロ校正）を選択し、「翻訳」をクリックします；
4. 訳文はチャットのバブル形式で段落ごとに画面へ表示され、訳文のコピー、原文の確認、追加の指示によるトーンやスタイルの調整が続けられます。

ファイルの翻訳は第5章を参照してください。

## 第3章 ロールと権限

テナント内には 3 つのロールがあり、権限が順に拡大します：

| ロール | 該当者 | 表示可能な機能 |
|------|--------|----------|
| **一般ユーザー** | 全メンバー | リアルタイム翻訳、翻訳チケット（作成/閲覧/ダウンロード）、対照編集、通知センター、AI アシスタント、マイアカウント；インターフェース言語、職種設定 |
| **部門管理者** | 組織管理者が指定 | 一般ユーザーの全機能 + 管理コンソールの基本メニュー：**概況**（使用量明細を含む）、**フィードバック／承認**（チケットの承認、フィードバックへの返信）、**ナレッジベース**（自部門パッケージ/部門間パッケージ）、トップバーの「ナレッジベースをアップロード」 |
| **組織管理者** | 企業ごとに最低 1 名（作成者または権限委任者） | 部門管理者の全機能 + **組織とメンバー**（部門ツリー、メンバー、招待コード、予算）、**外部呼び出し**（API Key、Webhook、SDK）、**ナレッジベース**（組織パッケージ/部門パッケージ/部門間パッケージの全タイプ）、ブランド名（固定訳）のメンテナンス、SCIM 組織同期の設定 |

説明：

- 本書は上記のテナント内ロールのみを扱い、プラットフォーム運営機能は範囲外です。
- 「フィードバック／承認」タブ内の「メモリ審査」「フィードバックアーカイブ完了」などの操作はプラットフォーム側のプロセスで、テナント画面には表示されませんので、意識する必要はありません。
- 権限に関する疑問は貴社の組織管理者にご連絡ください。

### 3.1 パーソナル版のユーザー

登録時に「パーソナル」アカウント種別を選択すると（組織コードも招待コードも不要）、**パーソナル版**が開始されます——トップバーのIDバッジに「パーソナル版」と表示され、アカウントは自分だけで管理し、企業のメンバーや部門の概念はありません。

パーソナル版で利用可能な機能：

| 機能 | 説明 |
|------|------|
| 3 つのワークスペース | リアルタイム翻訳、翻訳チケット、対照編集。企業版と完全に同一 |
| 管理コンソール | トップバーのアカウントメニューから入場：**ナレッジベース**（自分の用語表をアップロード・管理、自分だけに公開・利用可能）、**外部呼び出し**（API Key のセルフ発行。ブラウザ拡張/Word アドイン/SDK の利用に必要）、**概況**（自分の使用量明細） |
| 自分の職種 | 企業版と同じく、職務に応じてロールパッケージが自動アセンブル（7.5 を参照） |
| セルフサービスページ | その他 → マイアカウント；パスワード変更、メールアドレス変更、通知センター、アカウント削除 |

企業版との違い：

- **「組織とメンバー」がない**：部門、メンバー作成、部門予算などの管理ニーズは存在しません；
- **チケットに承認プロセスがない**：作成した翻訳チケットは直接キューに入り実行されます。「承認待ち」で停止することはありません；
- 企業専用サブドメインも組織共有ナレッジベースもありません。業種パッケージ、言語文化パッケージなどプラットフォーム共通のナレッジベースは通常どおり自動的に有効になります。

パーソナル版の額度または残高が不足した場合は、画面の案内に従ってご対応ください。

## 第4章 リアルタイム翻訳（ワークスペース）

「リアルタイム翻訳」はログイン後のデフォルトページで、全画面のチャットボックス——履歴が上、入力は下に固定されています。

### 4.1 入力エリア（入力カード下部のツールバー）

1 枚の入力カードの中に、1 行ずつ自動伸長する入力欄と 1 行のツールバーがあります：

| コントロール | 説明 |
|------|------|
| 原文・自動検出 | 原文言語を選択、デフォルトは自動検出 |
| ターゲット言語 | クリックでピッカーを開く；言語は「ナレッジベース言語 / その他の言語（AI翻訳）」にグループ化され、「その他の言語…」で全言語を検索可能；選択済み言語はチップで表示、3 を超えると「+n」に折りたたまれ、展開すると個別に削除できます |
| プロ校正 / 高速 | 翻訳モード。高速＝AI 初訳+校正で軽量・高スループット；プロ校正＝ナレッジベース用語校正 + 品質評価 + ハード検証ゲートのフルフローで、正式公開コンテンツ向け |
| 圧縮翻訳 | チェックすると訳文が長さ制約に従収束。見出し、ボタン文言など文字数制限のあるシーンに適する |
| 翻訳（メインボタン） | 翻訳を開始；生成中は「生成を停止」で中断できます |

送信前に消費予測が表示されます。残高不足または額度を使い切った場合は画面に提示があり、管理者へ連絡するよう案内されます。

### 4.2 チャットと結果

- 原文と訳文は同じバブル枠内に上下で表示され、訳文はストリーミングで段落ごとに画面へ出てきます。
- 各訳文に生成方式がタグ付けされます：**完全一致 / 曖昧マッチ / 意味類似**（ナレッジベース由来）または**オンライン翻訳**（AI 生成）；ナレッジベースの用語にヒットした場合はハイライト表示されます。
- バブル操作：訳文のコピー、原文の確認；続けて指示を送れば AI にトーンやスタイルの調整を依頼でき、文脈は維持されます。
- 翻訳プロセスの各工程（用語検索 → 機械翻訳 → 用語校正 → 翻訳完了）は画面にフェーズ表示されます。

### 4.3 セッション管理

チャットボックス上部に次を提供します：

- **本セッションのメッセージ検索**（ショートカットキー Ctrl/⌘+K）；
- **会話記録のエクスポート**（Markdown ファイル）；
- **会話のクリア**。

### 4.4 使用量表示

画面上の消費量は統一して「ポイント」で表示し、「翻訳可能な文数の目安」にも換算します。入力エリア付近に常時表示：残高（ポイント ≈ 文数）、本日の消費、部門予算の進捗（部門に所属し予算がある場合）。

## 第5章 翻訳チケット（ドキュメント翻訳）

すべての**ファイル翻訳**は「翻訳チケット」画面から開始し、完全なフローを辿ります：作成 → （企業設定により）承認 → 翻訳 → 納品。

### 5.1 チケットの作成

「翻訳ジョブを作成」をクリックし、「テキスト」または「ファイル」タブを選択します：

- **テキスト**：長いテキストを貼り付け、ターゲット言語とモードを選択して直接作成します。
- **ファイル**：1 つまたは複数のファイルをアップロードし、複数のターゲット言語を一度にチェックできます（成果物は zip にまとめてダウンロード）。

主要フィールド：

| フィールド | 説明 |
|------|------|
| 納品形式 | **レイアウト復元モード**（デフォルト）：元のフォーマットで訳文ファイルを納品（レイアウト復元）、併せてプレーンテキストの .md フォールバック成果物を添付；**プレーンテキストのみ**：本文をローカル抽出して翻訳し、訳文 .md を納品、レイアウトは保証しません（旧形式 doc/ppt/xls、odt/epub/rtf など向け） |
| モード | 高速（ナレッジベースなし）/ プロ校正 |
| ターゲット言語 | 複数選択可 |
| 消費予測 | 作成前に「消費予定 {n} 文 · 残高 {n} 文」を表示 |

ファイル形式の対応状況：

| カテゴリ | 形式 | 納品 |
|------|------|------|
| レイアウト復元可 | docx、pptx、xlsx、pdf、txt、csv、md | 同一形式の訳文ファイル |
| 対照表で納品 | srt、vtt、json、yaml など | 原文/訳文対照 xlsx |
| プレーンテキストのみ | doc、ppt、xls の旧形式、odt/ods/odp、rtf、epub | 訳文 .md |

制限と説明：

- 1 枚のチケットあたりのファイル数とサイズに上限があります；PDF が 40MB または 120 ページを超える場合は、友好的にお断りし、先に docx へ変換するよう案内します。
- スキャン版 PDF（画像のみ）には対応しません；画像内の文字は製品方針により翻訳しません。
- レイアウト復元に万一失敗した場合、そのファイルは自動的に .md 納品へダウングレードされ、サイト内通知でお知らせします。チケット全体が失敗することはありません。

### 5.2 チケットの状態と遷移

「マイジョブ」リストは状態で絞り込みできます。状態の意味：

```
キュー投入済み → 翻訳中 → 完了
承認待ち → 承認済み → 翻訳中 …    （企業が承認を有効にしている場合）
        └→ 却下済み
進行中のいずれの状態 → キャンセル済み
```

- 進行中では「キャンセル」をクリックできます；終了済みは「削除」できます。
- 貴社で承認を有効にしている場合、チケットはまず「承認待ち」に置かれ、部門管理者/組織管理者が管理コンソールの「フィードバック／承認」にある承認デスクで承認（承認済み）または却下（却下済み、理由付き）します。

### 5.3 進捗の確認とダウンロード

チケットを開くと「実行進捗」ステップバーが表示されます。工程には：解析抽出 → ナレッジベースマッチ → AI 初訳 → プロ校閲 → ハードゲ検証 → 文化チェック → ファイル書き戻し などを含みます（モードとファイル形式により表示が変わります）。

- 完了後「ダウンロード」をクリックして訳文を取得します；プレーンテキストのフォールバックは「訳文テキストのみダウンロード（.md）」で利用できます。
- 多言語/複数ファイルのタスクはダウンロードするとそのまま zip パッケージです。

### 5.4 品質レポート

プロ校正モードの完了済みチケットには「品質レポート」ブロックが付きます。総合結論（品質チェック合格 / 品質チェック不合格 / 品質チェック要確認）、機械評価スコア（満点 100）および段落ごとの説明。結果に異議がある場合は、チケット詳細の「ご意見・問題の送信」から申し立ててください。管理者が管理コンソールで確認し返信します。

### 5.5 対照編集への連携

完了済みチケットはワンクリックで「対照編集」に入り段落ごとに再レビューできます。次の章を参照してください。

## 第6章 対照編集

「対照編集」はチケットの訳文に対する人的最終レビューに使用します：

1. チケット詳細から遷移、または「対照編集」画面でチケット ID/チケット番号を入力して「読み込み」；
2. 左カラムに原文、右カラムに訳文を段落ごとに並べて対照表示、ナレッジベース用語は原文側にハイライト；
3. 各段落ごとに：**承認** / **却下**（コメント/却下理由を入力）/ 訳文を直接修正；
4. 「保存」をクリックして人的修正を確定します。

人力で確認済みの高品質な対訳文は翻訳メモリの最良のソースです——企業のナレッジベース管理者が整理してインポートできます（第7章を参照）。

## 第7章 ナレッジベースと翻訳メモリ

ナレッジベース（KB）は翻訳に「貴社を理解させる」もの：用語の統一、確認済み訳文の再利用、コンプライアンス表現の固定。

### 7.1 4 つのコンテンツ層

| 層 | 内容 | 典型用途 |
|----|------|----------|
| L1 用語 | 用語対訳（ブランド名・製品名の固定訳を含む） | 表記の強制統一 |
| L2 翻訳メモリ（TM） | 確認済みの原文/訳文ペア | 全文またはフラグメントの直接再利用 |
| L3 安全表現 | 禁止語 / 置換ペア / スタイル規範 | 言語文化ハードゲート検証、訳文中で自動ブロックまたは置換 |
| L4 フラグメント | 断片的な表現、句型リファレンス | 曖昧マッチの例文参考 |

翻訳時のヒット優先順位：自組織チェーン上の部門パッケージ（自部門→上位→ルート、近いものが優先）＞ 組織パッケージ ＞ 業種/言語文化パッケージ；部門間共有パッケージは管理者が有効にして初めてフォールバック層として参加します。

### 7.2 誰が何を保守できるか

| 操作 | 必要ロール |
|------|----------|
| トップバー「ナレッジベースをアップロード」（ファイル認識 → パッケージ選択 → インポート） | 部門管理者以上 |
| **部門パッケージ**、**部門間パッケージ**の作成/保守 | 部門管理者以上 |
| **組織パッケージ（自社）**、部門間共有の総スイッチ、パッケージレベルの権限付与の作成/保守 | 組織管理者 |
| 「ブランド名」（ブランド/製品の固定訳）の保守 | ナレッジベースパネルにアクセスできるロール |
| 対訳コーパス / TMX のインポート、TMX のエクスポート | 部門管理者以上 |
| 「言語文化ルール（安全表現）」の保守 | 部門管理者以上 |

### 7.3 パッケージのタイプ

- **組織パッケージ（自社）**：企業全体で有効；
- **部門パッケージ（自部門）**：自部門と組織チェーン内でのみ表示可能、部門単位の用語隔離を実現；
- **部門間パッケージ（共有）**：デフォルトでは他部門に貸出なし、パッケージ単位の「部門間共有・ON/OFF」と企業戦略スイッチの両方で他部門への有効可否が決まります。

### 7.4 インポート方法

管理コンソールの「ナレッジベース」パネルに入ります（部門管理者以上）：

- **ファイルインポート**：用語表/ドキュメントをアップロード、システムが認識後に選択したパッケージへ書き込み；
- **対訳コーパス / TMX インポート**：翻訳メモリへ一括書き込み、主要 CAT ツール（Trados/memoQ など）出力の TMX に対応；
- **TMX エクスポート**：企業のメモリを既存のツールチェーンへ持ち戻し。

プラットフォーム側では業種に応じて汎用の「業種パッケージ / 言語文化パッケージ」も自動アセンブルします。企業の保守は不要で、翻訳時に自動的に有効になります。

### 7.5 自分の職種（全ユーザー）

アカウントメニュー →「自分の職種」：プリセットの職種辞書（15 以上の職業）から自分の職務ロールを選択します。翻訳時にシステムが対応するロールパッケージを自動アセンブルし、用語とトーンをあなたの業務シーンに近づけます。

## 第9章 組織とメンバー管理（組織管理者）

入口：アカウントメニュー →「管理コンソールへ」→ 左側の「組織とメンバー」。

### 9.1 組織構造

- **新規組織 / 新規部門**：企業の多層組織ツリーを維持。リネームに対応。
- **部門予算**：部門に「月額予算を割り当て」、その部門メンバーの翻訳使用量をコントロール；メンバーの画面には部門予算の進捗が表示されます。

### 9.2 メンバーアカウント

「メンバーアカウント」画面で企業の全アカウントを管理します：

- **ユーザーを追加**：メンバーを個別に作成、ロール（一般ユーザー / 部門管理者 / 組織管理者）と所属組織を指定；
- **ユーザーの一括インポート (Excel)**：複数メンバーを一度に作成、初期パスワードはメールで通知され、メンバーは初回ログイン時にパスワード変更を要求されます；
- 既存メンバーに対して：**パスワードリセット**、アカウントの**有効化/無効化**、ロールと組織所属の調整。

### 9.3 メンバーを招待

「メンバーを招待」画面で**招待コード**を生成します（複数作成可、参加させる組織階層を指定可）。組織コード + 招待コードを同僚に伝え、登録画面で入力すると対応する部門に参加します。

### 9.4 SCIM 組織同期（オプション）

「その他 → マイアカウント」内の SCIM カード：企業が Okta、Entra ID などの ID ソースを使用する場合、SCIM エンドポイントとトークンを取得してメンバーの自動作成/同期を行えます；有効化後、社員はログイン画面の SSO ボタンでパスワード不要ログインできます。

## 第10章 外部呼び出しと統合（組織管理者）

入口：管理コンソール →「外部呼び出し」。3 つのサブページ：**オープン API**、**Webhook 通知**、**公式 SDK**。

### 10.1 オープン API の Key

- **API Key の発行**：作成時に平文で**一度だけ**完全表示されますので、ただちに保存してください；
- Key の**有効化/無効化、ローテーション、1 日上限の設定、削除**に対応；
- Key は自社のテナントとポイント換算に紐付き、API 経由の消費は Web と同一アカウントに計上されます。

オープン API の提供内容：非同期翻訳タスク（作成 → ポーリング → ダウンロード、複数ファイル・多言語に対応、成果物は zip にまとめ可）、同期短文翻訳（≤5000 文字、≤5 言語）、残高と使用量の照会、ナレッジベース統計。インターフェースドキュメントはブラウザでサイトの `/openapi/docs` にアクセスして閲覧できます。

### 10.2 Webhook コールバック

コールバック URL を登録しイベント（例：`translation.completed`）を購読すると、翻訳完了時にプラットフォームが貴社のシステムへ能動通知します；署名検証（X-Signature）、テスト送信、配信履歴の確認と再送に対応します。

### 10.3 公式 SDK とプラグイン

「公式 SDK」ページに 3 端末のインストールガイドとダウンロード入口を提供します：

| 端末 | 入手方法 | 用途 |
|----|----------|------|
| Python | `pip install langcross-translator` | プログラムからの翻訳、バッチタスク |
| TypeScript | `npm i @langcross/translator-sdk` | Node/フロントエンド統合 |
| Java | Maven ソース配布 | 企業内システム連携 |
| ブラウザ選択翻訳拡張 | 同ページで zip をダウンロード（アプリストア経由なし） | 任意の Web ページでテキストを選択→表示される「訳」ボタンをクリック→バブルで訳文を確認しコピー；ショートカットキー Alt+Shift+T（macOS は Alt+T） |
| Word アドイン | サイトがアドインマニフェストを提供、Word の「挿入 → アドインを取得 → マイ アドインのアップロード」でサイドロード | Word 内で選択テキストを翻訳しドキュメントへ挿入 |
| VS Code 拡張 | リポジトリ内の vscode-extension | エディタ内で選択テキストをその場で翻訳、用語検索 |

**拡張/アドインの設定**（選択翻訳拡張の popup と Word ウィンドウは同じロジック）：**サービスアドレス**（サイトのルートアドレス）、**API Key**（本書 10.1 で発行）、**ターゲット言語**、**翻訳モード**（高速/プロ校正）を入力すれば利用できます。用語と翻訳メモリはサイト内と一致します。

⚠ 拡張のアップグレード後にスタイルが変わっていない場合：新しい zip で**同じディレクトリ**を上書きし、`chrome://extensions` でその拡張カードの**更新**ボタンをクリックしてください。

### 10.4 部門管理者の範囲

部門管理者が API 統合を必要とする場合は、組織管理者に Key の発行を依頼してください。「外部呼び出し」メニューは部門管理者には表示されません。

## 第12章 よくある質問

**Q1：翻訳ボタンが押せない / 額度不足の提示が出る？**
現在の残高または部門予算を使い切っています。一般ユーザーは企業の管理者にご連絡ください；管理者は管理コンソールで使用量明細を確認できます。

**Q2：ファイル翻訳の入口はどこ？チャット画面で添付できなくなった？**
ファイル翻訳は「翻訳チケット → ファイル」に統一されました。チャットボックスはプレーンテキストの翻訳のみです。

**Q3：PDF の翻訳が断られた？**
40MB または 120 ページを超える PDF は先に docx へ変換してからチケットを作成してください；スキャン版 PDF（全面が画像）は現時点では未対応です。

**Q4：訳文が自分の用語表と一致しないのはなぜ？**
用語がナレッジベースへインポート済みか、そのパッケージが自部門に表示可能かを確認してください（第7章）；正式公開のコンテンツは「プロ校正」モードを選択してください。

**Q5：納品された docx のレイアウトが原文と異なる？**
「レイアウト復元モード」は大半の場合レイアウトを保持します；一部の複雑なレイアウトは .md テキスト納品へダウングレードされ、サイト内通知でお知らせします。.md をダウンロード後に対照編集で再レビューするか、フィードバックを送信してください。

**Q6：翻訳完了したのに残高が変わらない？**
計測は翻訳完了の瞬間に同期して保存されます。ページが更新されていなければ手動で一度リフレッシュしてください；それでも異常があればフィードバックを送信してください。

**Q7：スマホ/タブレットでも使える？**
ブラウザから直接アクセスするだけで使えます、インターフェースは狭い画面に自動適応；拡張とアドインはデスクトップ版中心です。

**Q8：画面の文字が見切れる、またはレイアウトがおかしい（アラビア語など）？**
まず他の言語に切り替えて一部の語句だけの問題か確認し、フィードバックチャネルにスクリーンショットを送ってください。
