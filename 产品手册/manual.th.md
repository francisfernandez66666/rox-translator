## 1. ภาพรวมผลิตภัณฑ์

**LangCross（能言）** คือแพลตฟอร์มการทำงานร่วมกันด้านการแปลด้วย AI สำหรับองค์กรและทีม ซึ่งรวบรวมวิธีการแปลสามรูปแบบเข้ากับระบบสินทรัพย์ทางภาษาขององค์กรไว้ในที่เดียว:

| ความสามารถ | คำอธิบาย |
|------|------|
| แปลทันที | การแปลข้อความแบบบทสนทนา พิมพ์แล้วแปลได้เลย รองรับการแปลไปยังภาษาเป้าหมายหลายภาษาในครั้งเดียว |
| คำขอการแปล | อัปโหลดไฟล์ docx / pptx / xlsx / pdf ฯลฯ แล้วดำเนินการครบวงจร «สร้างคำขอ → อนุมัติ → แปล → ส่งมอบ» พร้อมส่งมอบไฟล์คำแปลคงรูปแบบเดิมไว้ |
| แก้ไขแบบเทียบเคียง | ต้นฉบับและคำแปลแสดงสองคอลัมน์เทียบกันทีละย่อหน้า สามารถแก้ไข อนุมัติ หรือตีกลับพร้อมบันทึกหมายเหตุได้ |
| คลังความรู้ / ความจำการแปล (KB/TM) | คำศัพท์ขององค์กร ประโยคคู่สองภาษาที่ยืนยันแล้ว และชื่อแบรนด์ที่แปลตายตัว จะถูกบันทึกไว้ในคลังความรู้และจับคู่อัตโนมัติขณะแปลเพื่อให้การใช้คำเป็นหนึ่งเดียว |

จุดเด่นหลัก:

- **แปลได้กว่า 40 ภาษา** ตัวโปรแกรมเองมีให้ใช้งาน 12 ภาษา (简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Русский、العربية、ไทย) โดยอินเทอร์เฟซภาษาอาหรับจัดวางแบบจากขวาไปซ้าย
- **สองโหมดการแปล**: «รวดเร็ว» เบาแรงและผ่านปริมาณสูง; «พิสูจน์อักษรมืออาชีพ» มาพร้อมการปรับคำศัพท์ด้วยคลังความรู้ การประเมินคุณภาพ และประตูกวดขันการตรวจสอบ เหมาะกับเนื้อหาที่ต้องเผยแพร่ออกภายนอก
- **การแยกส่วนระดับองค์กร**: ข้อมูล คลังความรู้ และสมาชิกของแต่ละ tenant แยกจากกันโดยสมบูรณ์; ภายในองค์กรยังแยกคลังความรู้และงบตามแผนกอีกชั้นหนึ่ง
- **สอดคล้องทุกแพลตฟอร์ม**: นอกเหนือจากเวอร์ชันเว็บ ยังมีส่วนขยายแปลคำที่เลือกในเบราว์เซอร์ แอปพลิเคชันเสริมสำหรับ Word ปลั๊กอิน VS Code และ Open API/SDK โดยคำแปลทุกช่องทางใช้มาตรฐานเดียวกับเวอร์ชันเว็บ

## 2. เริ่มต้นใช้งานอย่างรวดเร็ว

### 2.1 เข้าสู่ระบบ

เปิดที่อยู่ที่องค์กรของคุณกำหนดให้ (โดเมนของแพลตฟอร์มหรือ subdomain เฉพาะขององค์กร) แล้วกรอก**ชื่อผู้ใช้**และ**รหัสผ่าน**บนหน้าเข้าสู่ระบบ

- ลืมรหัสผ่าน: คลิก «ลืมรหัสผ่าน» แล้วรับการยืนยันผ่านอีเมลที่ผูกไว้เพื่อตั้งรหัสใหม่
- หากองค์กรเปิดใช้ระบบระบุตัวตนแบบรวมศูนย์ (SSO) หน้าเข้าสู่ระบบจะแสดงปุ่ม «หรือเข้าสู่ระบบด้วยตัวตนขององค์กร» คลิกแล้วเข้าสู่ระบบด้วยบัญชีองค์กรได้ทันที
- การเข้าสู่ระบบครั้งแรก: หากผู้ดูแลไม่ได้กำหนดอีเมลไว้ตอนสร้างบัญชี ระบบจะแสดงหน้าต่าง «กรุณาผูกอีเมล» ที่ปิดไม่ได้ ขอให้ดำเนินการผูกอีเมลให้เรียบร้อยก่อน บัญชีที่สร้างแบบชุดจะถูกบังคับ «กรุณาเปลี่ยนรหัสผ่านในการเข้าสู่ระบบครั้งแรก»

### 2.2 สมัคร / เข้าร่วมองค์กร

มีสองเส้นทาง:

- **เข้าร่วมองค์กรที่มีอยู่แล้ว**: ตอนสมัครให้กรอกรหัสองค์กร + **รหัสเชิญ** (จำเป็น ขอให้รหัสจากองค์กรของคุณ) ก็จะเข้าร่วมแผนกที่ตรงกันกลายเป็นผู้ใช้ทั่วไป เมื่อเข้าหน้าสมัครผ่าน subdomain เฉพาะขององค์กร (`รหัสองค์กร.โดเมน`) ข้อมูลองค์กรจะกรอกอัตโนมัติ และช่องทางนี้สร้างได้เฉพาะสมาชิกทั่วไปขององค์กรนั้น
- **สร้างองค์กรใหม่**: เว้นรหัสเชิญว่างไว้ ระบบจะสร้างองค์กรใหม่และผู้สมัครกลายเป็นผู้ดูแลองค์กรขององค์กรนั้น ซึ่งสามารถเชิญเพื่อนร่วมงานต่อไปได้ (ดูบทที่ 9)

ขั้นตอนการสมัครมีผู้ช่วย AI นำทาง: เลือกประเภทบัญชี (ส่วนบุคคล/องค์กร) → สถานะในองค์กร (ผู้ดูแลสร้างองค์กร / สมาชิกเข้าร่วมด้วยรหัสเชิญ) → อุตสาหกรรมและบทบาทอาชีพ → กรอกข้อมูลบัญชี ทำตามคำแนะนำทีละขั้นตอนได้ รองรับย้อนกลับขั้นก่อนหน้า การเลือก «ส่วนบุคคล» จะเปิดใช้งานรุ่นบุคคล ขอบเขตฟีเจอร์ดูที่ [3.1 ผู้ใช้รุ่นบุคคล](#31-ผู้ใช้รุ่นบุคคล)

### 2.3 ทำความรู้จักอินเทอร์เฟซ

หลังเข้าสู่ระบบจะเข้ามาที่เวิร์กสเปซ โซนหลักประกอบด้วย:

| โซน | เนื้อหา |
|------|------|
| แถบบน | แท็บเวิร์กสเปซสามแท็บ: **แปลทันที**, **คำขอการแปล**, **แก้ไขแบบเทียบเคียง**; ด้านขวาเป็นป้ายยอดคงเหลือคะแนน กริ่งการแจ้งเตือน สวิตช์ภาษา และเมนูบัญชี; ผู้ดูแลแผนกขึ้นไปจะเห็นปุ่ม «อัปโหลดคลังความรู้» และทางเข้า «ไปหน้าผู้ดูแล» เพิ่มเติม |
| ลิ้นชัก «เพิ่มเติม» | ทางเข้าหน้าช่วยเหลือตนเอง เช่น บัญชีของฉัน และส่วนท้ายหน้า |
| พื้นที่เนื้อหาหลัก | หน้าทำงานของแท็บปัจจุบัน |
| «ผู้ช่วย AI» มุมขวาล่าง | วิดเจ็ตผู้ช่วยอัจฉริยะที่เรียกใช้ได้ทุกเมื่อ (ดูบทที่ 11) |

- **เปลี่ยนภาษาอินเทอร์เฟซ**: เมนูภาษาบนแถบบน ตัวเลือกแต่ละภาษาจะแสดงด้วยชื่อในภาษานั้นเอง (เช่น «日本語» «한국어») เมื่อเลือกแล้วจะมีผลทันทีทั้งเว็บ การเข้าถึงผ่านเบราว์เซอร์ครั้งแรกจะตรวจจับตามระบบภาษาของเครื่องอัตโนมัติ
- **อุปกรณ์เคลื่อนที่**: ใช้ผ่านเบราว์เซอร์บนสมาร์ตโฟน/แท็บเล็ตได้โดยตรง บนหน้าจอแคบ แถบข้างของหน้าผู้ดูแลจะเปลี่ยนเป็นเมนูแบบลิ้นชักอัตโนมัติ
- **เมนูบัญชี** (อวาตาร์มุมขวาบน): ไปหน้าผู้ดูแล (ผู้ดูแลแผนกขึ้นไป) / กลับสู่เวิร์กสเปซ, เปลี่ยนรหัสผ่าน, เปลี่ยนอีเมล, บทบาทอาชีพของฉัน, ออกจากระบบ

### 2.4 แปลครั้งแรกให้สำเร็จ

1. วางข้อความที่ต้องการแปลลงในช่องป้อนของแท็บ «แปลทันที»;
2. ตรวจสอบภาษาต้นทาง (ค่าเริ่มต้น «ตรวจจับอัตโนมัติ») แล้วแตะตัวเลือกภาษาเป้าหมายเพื่อเลือกหนึ่งหรือหลายภาษา (ตัวเลือกจัดกลุ่มเป็น «ภาษาฐานความรู้ / ภาษาอื่น ๆ»);
3. เลือกโหมด (รวดเร็ว / พิสูจน์อักษรมืออาชีพ) แล้วกดปุ่ม «แปล»;
4. คำแปลจะแสดงทีละช่วงในรูปแบบฟองบทสนทนา คุณสามารถคัดลอกคำแปล ดูต้นฉบับ หรือถามต่อเพื่อปรับสไตล์ได้

## 3. บทบาทและสิทธิ์

ภายใน tenant มีสามระดับบทบาท สิทธิ์ขยายตามลำดับ:

| บทบาท | ใครคือผู้ใช้ | ฟีเจอร์ที่มองเห็น |
|------|--------|----------|
| **ผู้ใช้ทั่วไป** | สมาชิกทุกคน | แปลทันที, คำขอการแปล (สร้าง/ดู/ดาวน์โหลด), แก้ไขแบบเทียบเคียง, ศูนย์ประกาศ, ผู้ช่วย AI, บัญชีของฉัน; การตั้งค่าภาษาอินเทอร์เฟซและบทบาทอาชีพ |
| **ผู้ดูแลแผนก** | ผู้ดูแลองค์กรเป็นผู้แต่งตั้ง | ฟีเจอร์ทั้งหมดของผู้ใช้ทั่วไป + เมนูพื้นฐานของหน้าผู้ดูแล: **ภาพรวม** (รวมรายละเอียดการใช้), **ข้อเสนอแนะ / การอนุมัติ** (อนุมัติคำขอ, ตอบกลับข้อเสนอแนะ), **คลังความรู้** (แพ็กแผนก/แพ็กข้ามแผนก), ปุ่ม «อัปโหลดคลังความรู้» บนแถบบน |
| **ผู้ดูแลองค์กร** | ทุกองค์กรมีอย่างน้อยหนึ่งคน (ผู้สร้างหรือผู้ได้รับมอบหมาย) | ฟีเจอร์ทั้งหมดของผู้ดูแลแผนก + **องค์กรและสมาชิก** (ต้นไม้แผนก, สมาชิก, รหัสเชิญ, งบประมาณ), **การเรียกใช้จากภายนอก** (API Key, Webhook, SDK), **คลังความรู้** (ทุกประเภทแพ็ก: แพ็กองค์กร/แพ็กแผนก/แพ็กข้ามแผนก), การบำรุงรักษาชื่อแบรนด์ (คำแปลตายตัว), การตั้งค่าซิงค์องค์กร SCIM |

คำอธิบาย:

- คู่มือนี้ครอบคลุมเฉพาะบทบาทภายใน tenant ดังกล่าว ไม่ครอบคลุมฟังก์ชันการดำเนินงานของแพลตฟอร์ม
- การดำเนินการที่มีข้อความอย่าง «ตรวจสอบความจำ» «จัดเก็บข้อเสนอแนะเป็นแฟ้มถาวร» ในแท็บ «ข้อเสนอแนะ / การอนุมัติ» เป็นกระบวนการฝั่งแพลตฟอร์ม ไม่ปรากฏในอินเทอร์เฟซของ tenant ไม่ต้องสนใจ
- หากมีข้อสงสัยเรื่องสิทธิ์ กรุณาติดต่อผู้ดูแลองค์กรขององค์กรคุณ

### 3.1 ผู้ใช้รุ่นบุคคล

เลือกประเภทบัญชี «ส่วนบุคคล» ตอนสมัคร (ไม่ต้องใช้รหัสองค์กรและรหัสเชิญ) จะได้เปิดใช้งาน**รุ่นบุคคล** — ป้ายตัวตนบนแถบบนแสดง «รุ่นบุคคล» บัญชีอยู่ภายใต้การจัดการของคุณเอง ไม่มีแนวคิดสมาชิกองค์กรและแผนก

ฟีเจอร์ที่รุ่นบุคคลใช้งานได้:

| ฟีเจอร์ | คำอธิบาย |
|------|------|
| เวิร์กสเปซสามแท็บ | แปลทันที, คำขอการแปล, แก้ไขแบบเทียบเคียง เหมือนรุ่นองค์กรทุกประการ |
| หน้าผู้ดูแล | เข้าได้จากเมนูบัญชีบนแถบบน: **คลังความรู้** (อัปโหลดและดูแลตารางคำศัพท์ของตนเอง เห็นและใช้ได้เฉพาะตัวเอง), **การเรียกใช้จากภายนอก** (ออก API Key ด้วยตนเอง ใช้คู่กับส่วนขยายเบราว์เซอร์/แอปพลิเคชันเสริม Word/SDK), **ภาพรวม** (รายละเอียดการใช้ของตนเอง) |
| บทบาทอาชีพของฉัน | เช่นเดียวกับรุ่นองค์กร ระบบประกอบแพ็กบทบาทอัตโนมัติตามตำแหน่งงาน (ดู 7.5) |
| หน้าช่วยเหลือตนเอง | เพิ่มเติม → บัญชีของฉัน; เปลี่ยนรหัสผ่าน, เปลี่ยนอีเมล, ศูนย์ประกาศ, ยกเลิกบัญชี |

ความแตกต่างจากรุ่นองค์กร:

- **ไม่มี «องค์กรและสมาชิก»**: ไม่มีความต้องการจัดการแผนก การเปิดบัญชีสมาชิก หรืองบแผนก
- **คำขอไม่มีขั้นตอนอนุมัติ**: คำขอการแปลที่สร้างจะเข้าสู่คิวดำเนินการทันที ไม่ค้างอยู่ที่ «รออนุมัติ»
- ไม่มี subdomain เฉพาะขององค์กรและคลังความรู้ใช้ร่วมกันระดับองค์กร; แพ็กอุตสาหกรรมและแพ็กภาษา/วัฒนธรรมซึ่งเป็นคลังความรู้ทั่วไปของแพลตฟอร์มยังคงมีผลอัตโนมัติตามปกติ

เมื่อโควตาหรือยอดคงเหลือของรุ่นบุคคลไม่เพียงพอ ให้ทำตามคำแนะนำบนหน้าจอ

## 4. แปลทันที (เวิร์กสเปซ)

«แปลทันที» เป็นค่าเริ่มต้นหลังเข้าสู่ระบบ เป็นกล่องบทสนทนาเต็มจอ ประวัติอยู่ด้านบน ช่องป้อนยึดขอบล่าง

### 4.1 พื้นที่ป้อน (แถบเครื่องมือใต้กล่องป้อน)

กล่องป้อนหนึ่งใบ ประกอบด้วยช่องป้อนแบบปรับความสูงอัตโนมัติหนึ่งบรรทัดกับแถบเครื่องมือหนึ่งแถว:

| ควบคุม | คำอธิบาย |
|------|------|
| ต้นฉบับ·ตรวจจับอัตโนมัติ | เลือกภาษาต้นทาง ค่าเริ่มต้นคือตรวจจับอัตโนมัติ |
| ภาษาเป้าหมาย | แตะเปิดตัวเลือก; ภาษาจัดกลุ่มเป็น «ภาษาฐานความรู้ / ภาษาอื่น ๆ (AI)» และมี «ภาษาอื่น ๆ…» สำหรับค้นหาทุกภาษา; ภาษาที่เลือกแสดงเป็นแท็ก เกิน 3 ภาษาจะยุบเป็น «+n» แตะเปิดเพื่อกำจัดทีละตัว |
| พิสูจน์อักษรมืออาชีพ / รวดเร็ว | โหมดการแปล รวดเร็ว = AI แปลร่าง + ตรวจแก้ เบาแรงผ่านปริมาณสูง; พิสูจน์อักษรมืออาชีพ = กระบวนการเต็มตั้งแต่ปรับคำศัพท์ด้วยคลังความรู้ ประเมินคุณภาพ ผ่านประตูตรวจกวดขัน เหมาะกับเนื้อหาที่จะเผยแพร่อย่างเป็นทางการ |
| ย่อการแปล | เมื่อติ๊ก คำแปลจะถูกบีบตามข้อจำกัดความยาว เหมาะกับบริบทที่มีจำกัดตัวอักษรเช่นหัวเรื่องหรือข้อความปุ่ม |
| แปล (ปุ่มหลัก) | เริ่มการแปล; ระหว่างสร้างสามารถกด «หยุดสร้าง» ได้ |

ประมาณการการใช้จะแสดงก่อนส่ง เมื่อไม่เพียงพอบนหน้าจอจะแจ้งพร้อมระบุว่าให้ติดต่อผู้ดูแลเพื่อดำเนินการต่อ

### 4.2 บทสนทนาและผลลัพธ์

- ต้นฉบับและคำแปลแสดงซ้อนกันในกรอบฟองเดียวกัน คำแปลทยอยแสดงทีละช่วงแบบ streaming
- คำแปลแต่ละรายการกำกับด้วยที่มา: **จับตรงเป๊ะ / จับแบบคลุมเครือ / คล้ายตามความหมาย** (จากคลังความรู้) หรือ **แปลออนไลน์** (AI สร้างขึ้น); เมื่อจับคำศัพท์ในคลังความรู้ได้จะเน้นสว่างให้มองเห็น
- การกระทำบนฟอง: คัดลอกคำแปล, ดูต้นฉบับ; ส่งคำสั่งต่อไปให้ AI ปรับโทนหรือสไตล์ได้ บริบทจะต่อเนื่อง
- ขั้นตอนของกระบวนการแปล (ค้นคำศัพท์ → แปลด้วยเครื่อง → ปรับคำศัพท์ → แปลเสร็จ) มีข้อความแจ้งสถานะแต่ละขั้นบนหน้าจอ

### 4.3 จัดการเซสชัน

ด้านบนของกล่องบทสนทนามี:

- **ค้นหาข้อความในเซสชันนี้** (ทางลัด Ctrl/⌘+K);
- **ส่งออกบันทึกบทสนทนา** (ไฟล์ Markdown);
- **ล้างบทสนทนา**

### 4.4 แสดงการใช้

ปริมาณการใช้บนหน้าจอแสดงเป็น «คะแนน» ทั้งหมด พร้อมแปลงเป็น «จำนวนประโยคโดยประมาณ» บริเวณใกล้ช่องป้อนจะแสดงถาวร: ยอดคงเหลือ (คะแนน ≈ จำนวนประโยค), การใช้ของวันนี้, ความคืบหน้างบแผนก (เมื่อสังกัดแผนกที่มีงบกำหนด)

## 5. คำขอการแปล (การแปลเอกสาร)

การแปล**ไฟล์ทั้งหมด**เริ่มต้นที่หน้า «คำขอการแปล» และเดินกระบวนการครบวงจร: สร้างคำขอ → (ตามการตั้งค่าองค์กร) อนุมัติ → แปล → ส่งมอบ

### 5.1 สร้างคำขอ

คลิก «สร้างงานแปล» แล้วเลือกแท็บ «ข้อความ» หรือ «ไฟล์»:

- **ข้อความ**: วางข้อความยาว เลือกภาษาเป้าหมายและโหมด แล้วสร้างคำขอได้ทันที
- **ไฟล์**: อัปโหลดไฟล์หนึ่งหรือหลายไฟล์ เลือกหลายภาษาเป้าหมายพร้อมกันได้ (ผลผลิตบีบเป็น zip ให้ดาวน์โหลด)

ฟิลด์สำคัญ:

| ฟิลด์ | คำอธิบาย |
|------|------|
| วิธีส่งมอบ | **โหมดคืนรูปแบบไฟล์เดิม** (ค่าเริ่มต้น): ส่งมอบไฟล์คำแปลคงรูปแบบเดิม (คืนเลย์เอาต์) พร้อมแนบไฟล์ .md ข้อความล้วนเป็นตัวเลือกสำรอง; **โหมดข้อความล้วน**: สกัดเนื้อความในเครื่องแล้วแปล ส่งมอบเป็น .md คำแปล ไม่รับประกันเลย์เอาต์ (เหมาะกับรูปแบบเก่า doc/ppt/xls, odt/epub/rtf ฯลฯ) |
| โหมด | รวดเร็ว (ไม่ใช้คลังความรู้) / พิสูจน์อักษรมืออาชีพ |
| ภาษาเป้าหมาย | เลือกได้หลายภาษา |
| ประมาณการ | ก่อนสร้างแสดง «คาดว่าใช้ {n} ประโยค · คงเหลือ {n} ประโยค» |

การรองรับรูปแบบไฟล์:

| หมวดหมู่ | รูปแบบ | การส่งมอบ |
|------|------|------|
| คืนรูปแบบได้ | docx, pptx, xlsx, pdf, txt, csv, md | ไฟล์คำแปลรูปแบบเดียวกัน |
| ส่งมอบเป็นตารางเทียบคู่ | srt, vtt, json, yaml ฯลฯ | xlsx เทียบต้นฉบับ/คำแปล |
| ข้อความล้วนเท่านั้น | ตระกูลรูปแบบเก่า doc, ppt, xls, odt/ods/odp, rtf, epub | .md คำแปล |

ข้อจำกัดและคำอธิบาย:

- จำนวนและความจุไฟล์ต่อคำขอมีเพดานสูงสุด; PDF เกิน 40MB หรือ 120 หน้าจะถูกปฏิเสธอย่างสุภาพพร้อมแนะนำให้แปลงเป็น docx ก่อน
- ไม่รองรับ PDF แบบสแกน (ภาพล้วน); ข้อความภายในภาพไม่ถูกแปลตามนโยบายผลิตภัณฑ์
- หากการเขียนกลับเลย์เอาต์ล้มเหลว ไฟล์นั้นจะลดระดับเป็นการส่งมอบแบบ .md อัตโนมัติพร้อมแจ้งผ่านข้อความภายในระบบ ไม่ทำให้ทั้งคำขอล้มเหลว

### 5.2 สถานะคำขอและการเปลี่ยนสถานะ

รายการ «งานของฉัน» กรองตามสถานะได้ ความหมายสถานะ:

```
เข้าคิวแล้ว → กำลังแปล → เสร็จสิ้น
รออนุมัติ → อนุมัติแล้ว → กำลังแปล …    (เมื่อองค์กรเปิดใช้การอนุมัติ)
        └→ ตีกลับแล้ว
สถานะระหว่างดำเนินการใด ๆ → ยกเลิกแล้ว
```

- ระหว่างดำเนินการสามารถกด «ยกเลิก» ได้; ที่จบแล้วสามารถ «ลบ» ได้
- หากองค์กรของคุณเปิดใช้การอนุมัติ คำขอจะค้างที่ «รออนุมัติ» ก่อน ผู้ดูแลแผนก/ผู้ดูแลองค์กรจะเป็นผู้อนุมัติ (อนุมัติแล้ว) หรือตีกลับ (ตีกลับแล้ว พร้อมเหตุผล) ที่โต๊ะอนุมัติในหน้า «ข้อเสนอแนะ / การอนุมัติ» ของหลังบ้าน

### 5.3 ดูความคืบหน้าและดาวน์โหลด

เปิดคำขอเพื่อดูแถบขั้นตอน «ความคืบหน้าการดำเนินการ» ขั้นตอนได้แก่: สกัดเนื้อหา → จับคู่คลังความรู้ → AI แปลร่าง → พิสูจน์อักษรมืออาชีพ → ตรวจประตูแข็ง → ตรวจสอบวัฒนธรรม → เขียนกลับไฟล์ ฯลฯ (แสดงตามโหมดและประเภทไฟล์)

- เมื่อเสร็จกด «ดาวน์โหลด» รับไฟล์คำแปล; สำรองข้อความล้วนใช้ «ดาวน์โหลดเฉพาะข้อความคำแปล (.md)» ได้
- งานหลายภาษา/หลายไฟล์ เมื่อดาวน์โหลดจะเป็นแพ็ก zip

### 5.4 รายงานการตรวจคุณภาพ

คำขอที่เสร็จสิ้นในโหมดพิสูจน์อักษรมืออาชีพมีบล็อก «รายงานการตรวจคุณภาพ»: ข้อสรุปภาพรวม (ผ่านคุณภาพ / ไม่ผ่านคุณภาพ / คุณภาพน่าสงสัย) คะแนนประเมินอัตโนมัติ (เต็ม 100) และคำอธิบายเป็นช่วง หากเห็นต่างในผลลัพธ์ สามารถ «ส่งข้อเสนอแนะ» ที่หน้ารายละเอียดคำขอ ผู้ดูแลจะได้รับและตอบกลับในหน้าผู้ดูแล

### 5.5 ต่อยอดสู่แก้ไขแบบเทียบเคียง

คำขอที่เสร็จสิ้นแล้วกดเข้าสู่ «แก้ไขแบบเทียบเคียง» เพื่อทบทวนทีละย่อหน้าได้ทันที ดูบทถัดไป

## 6. แก้ไขแบบเทียบเคียง

«แก้ไขแบบเทียบเคียง» ใช้สำหรับตรวจทานขั้นสุดท้ายโดยมนุษย์กับคำแปลของคำขอ:

1. กระโดดจากหน้ารายละเอียดคำขอ หรือ «โหลด» ด้วย ID คำขอ/เลขที่คำขอที่หน้า «แก้ไขแบบเทียบเคียง»;
2. ซ้ายเป็นต้นฉบับ ขวาเป็นคำแปล เทียบกันทีละย่อหน้า คำศัพท์คลังความรู้จะเน้นสว่างฝั่งต้นฉบับ;
3. แต่ละย่อหน้าสามารถ: **อนุมัติ** / **ตีกลับ** (กรอกหมายเหตุ/เหตุผลตีกลับ) / แก้ไขคำแปลโดยตรง;
4. กด «บันทึก» เพื่อเก็บการแก้ไขโดยมนุษย์

ประโยคคู่คุณภาพสูงที่ผ่านการยืนยันโดยมนุษย์คือแหล่งวัตถุดีเยี่ยมของความจำการแปล — ผู้ดูแลคลังความรู้ขององค์กรสามารถรวบรวมและนำเข้าได้ (ดูบทที่ 7)

## 7. คลังความรู้และความจำการแปล

คลังความรู้ (KB) ทำให้การแปล «เข้าใจองค์กรของคุณ»: คำศัพท์เป็นเอกภาพ นำคำแปลที่ยืนยันแล้วกลับมาใช้ใหม่ และตรึงถ้อยคำที่สอดคล้องตามข้อกำหนด

### 7.1 เนื้อหาสี่ชั้น

| ชั้น | เนื้อหา | การใช้งานทั่วไป |
|----|------|----------|
| L1 คำศัพท์ | คู่คำศัพท์ (รวมชื่อแบรนด์ ชื่อผลิตภัณฑ์ที่แปลตายตัว) | บังคับใช้คำเป็นหนึ่งเดียว |
| L2 ความจำการแปล (TM) | คู่ประโยคต้นฉบับ/คำแปลที่ยืนยันแล้ว | นำกลับมาใช้ทั้งประโยคหรือเป็นท่อนย่อย |
| L3 วลีความปลอดภัย | คำต้องห้าม / คู่ทดแทน / เกณฑ์สไตล์ | ตรวจสอบประตูแข็งด้านภาษาวัฒนธรรม บล็อกหรือแทนที่อัตโนมัติในคำแปล |
| L4 ชิ้นส่วน | สำนวนกระจัดกระจาย อ้างอิงโครงสร้างประโยค | ตัวอย่างอ้างอิงสำหรับการจับคลุมเครือ |

ลำดับความสำคัญของการจับขณะแปล: แพ็กแผนกบนสายองค์กร (แผนกตนเอง→เหนือ→ราก ทับใกล้สุด) ＞ แพ็กองค์กร ＞ แพ็กอุตสาหกรรม/ภาษาวัฒนธรรม; แพ็กแชร์ข้ามแผนกต้องให้ผู้ดูแลเปิดก่อนจึงจะเข้าร่วมเป็นชั้นสำรองได้

### 7.2 ใครดูแลอะไรได้บ้าง

| การดำเนินการ | บทบาทขั้นต่ำ |
|------|----------|
| «อัปโหลดคลังความรู้» บนแถบบน (จำแนกไฟล์ → เลือกแพ็ก → นำเข้า) | ผู้ดูแลแผนกขึ้นไป |
| สร้าง/ดูแล**แพ็กแผนก**, **แพ็กข้ามแผนก** | ผู้ดูแลแผนกขึ้นไป |
| สร้าง/ดูแล**แพ็กองค์กร (องค์กรนี้)**, สวิตช์แชร์ข้ามแผนกหลัก, การอนุญาตระดับแพ็ก | ผู้ดูแลองค์กร |
| ดูแล «ชื่อแบรนด์» (คำแปลตายตัวของแบรนด์/ผลิตภัณฑ์) | ทุกบทบาทที่เข้าถึงแผงคลังความรู้ได้ |
| นำเข้าคู่ข้อความสองภาษา / TMX, ส่งออก TMX | ผู้ดูแลแผนกขึ้นไป |
| ดูแล «เกณฑ์ภาษาและวัฒนธรรม (วลีความปลอดภัย)» | ผู้ดูแลแผนกขึ้นไป |

### 7.3 ประเภทแพ็ก

- **แพ็กองค์กร (องค์กรนี้)**: มีผลทั้งองค์กร;
- **แพ็กแผนก (แผนกนี้)**: มองเห็นเฉพาะในแผนกตนเองและภายในสายองค์กร เพื่อแยกคำศัพท์ระดับแผนกออกจากกัน;
- **แพ็กข้ามแผนก (แชร์ร่วมกัน)**: ค่าเริ่มต้นไม่ให้องค์ส่วนอื่นยืมใช้ จะส่งผลต่อแผนกอื่นหรือไม่ขึ้นกับ «แชร์ข้ามแผนก · เปิด/ปิด» ระดับแพ็ก ร่วมกับสวิตช์นโยบายขององค์กร

### 7.4 วิธีนำเข้า

เข้าสู่แผง «คลังความรู้» ในหน้าผู้ดูแล (ผู้ดูแลแผนกขึ้นไป):

- **นำเข้าจากไฟล์**: อัปโหลดตารางคำศัพท์/เอกสาร ระบบจำแนกแล้วเขียนลงแพ็กที่เลือก;
- **นำเข้าคู่ข้อความสองภาษา / TMX**: เขียนความจำการแปลเป็นชุด เข้ากันได้กับ TMX ที่ส่งออกโดยเครื่องมือ CAT ยอดนิยม (Trados/memoQ ฯลฯ);
- **ส่งออก TMX**: นำความจำขององค์กรกลับไปใช้กับเครื่องมือเดิมของคุณ

ฝั่งแพลตฟอร์มยังประกอบ «แพ็กอุตสาหกรรม / แพ็กภาษาวัฒนธรรม» ที่เป็นเกณฑ์ทั่วไปตามอุตสาหกรรมอัตโนมัติ องค์กรไม่ต้องดูแล มีผลอัตโนมัติขณะแปล

### 7.5 บทบาทอาชีพของฉัน (ทุกบุคคล)

เมนูบัญชี → «บทบาทอาชีพของฉัน»: เลือกบทบาทตำแหน่งงานของคุณจากพจนานุกรมบทบาทสำเร็จรูป (กว่า 15 อาชีพ) ขณะแปลระบบจะประกอบแพ็กบทบาทที่ตรงกันอัตโนมัติ ทำให้คำศัพท์และโทนสอดคล้องกับบริบทการทำงานของคุณ

## 9. การจัดการองค์กรและสมาชิก (ผู้ดูแลองค์กร)

ทางเข้า: เมนูบัญชี → «ไปหน้าผู้ดูแล» → «องค์กรและสมาชิก» ด้านซ้าย

### 9.1 โครงสร้างองค์กร

- **สร้างองค์กร / สร้างแผนก**: ดูแลต้นไม้หลายระดับขององค์กร; รองรับการเปลี่ยนชื่อ
- **งบแผนก**: «จัดสรรงบรายเดือน» ให้แผนก คุมปริมาณการใช้แปลของสมาชิกแผนกนั้น; บนหน้าจอของสมาชิกจะแสดงความคืบหน้าของงบแผนก

### 9.2 บัญชีสมาชิก

หน้า «สมาชิก» จัดการบัญชีทั้งหมดขององค์กร:

- **เปิดบัญชีผู้ใช้**: สร้างสมาชิกทีละคน กำหนดบทบาท (ผู้ใช้ทั่วไป / ผู้ดูแลแผนก / ผู้ดูแลองค์กร) และตำแหน่งในองค์กร;
- **นำเข้าผู้ใช้แบบชุด (Excel)**: เปิดสมาชิกหลายคนพร้อมกัน รหัสผ่านเริ่มต้นส่งทางอีเมล สมาชิกจะถูกบังคับเปลี่ยนรหัสผ่านในการเข้าสู่ระบบครั้งแรก;
- กับสมาชิกที่มีอยู่แล้ว: **รีเซ็ตรหัสผ่าน**, **เปิด/ระงับ**บัญชี, ปรับบทบาทและแผนกที่สังกัด

### 9.3 เชิญพนักงาน

หน้า «เชิญพนักงาน» ใช้สร้าง**รหัสเชิญ** (สร้างได้หลายรหัส ระบุระดับองค์กรที่จะเข้าร่วมได้) แจ้งรหัสองค์กร + รหัสเชิญให้เพื่อนร่วมงาน เพียงกรอกในหน้าสมัครก็จะเข้าร่วมแผนกที่ตรงกัน

### 9.4 ซิงค์องค์กร SCIM (ทางเลือก)

การ์ด SCIM ใน «เพิ่มเติม → บัญชีของฉัน»: เมื่อองค์กรใช้ identity provider เช่น Okta, Entra ID สามารถรับ endpoint และโทเคน SCIM เพื่อเปิดใช้การซิงค์สมาชิกอัตโนมัติ; เมื่อเปิดใช้แล้ว พนักงานสามารถเข้าสู่ระบบได้โดยไม่ต้องกรอกรหัสผ่านด้วยปุ่ม SSO บนหน้าเข้าสู่ระบบ

## 10. การเรียกใช้จากภายนอกและการเชื่อมต่อระบบ (ผู้ดูแลองค์กร)

ทางเข้า: หน้าผู้ดูแล → «การเรียกใช้จากภายนอก» มีสามหน้าย่อย: **Open API**, **Webhook**, **SDK อย่างเป็นทางการ**

### 10.1 API Key แบบ Open API

- **ออก API Key**: ข้อความชัดเจนแสดงครบ**เพียงครั้งเดียว**ตอนสร้าง โปรดยันทึกทันที;
- รองรับ **เปิด/ระงับ, หมุนเวียน, กำหนดโควตารายวัน, ลบ** กับ Key;
- Key ผูกกับ tenant ขององค์กรคุณและหน่วยคะแนน การใช้ผ่าน API ถูกหักบัญชีเดียวกับเวอร์ชันเว็บ

Open API รองรับ: งานแปลแบบอะซิงโครนัส (สร้าง → polling → ดาวน์โหลด รองรับหลายไฟล์หลายภาษา ผลผลิตบีบ zip ได้), การแปลข้อความสั้นแบบซิงโครนัส (≤5000 อักขระ, ≤5 ภาษา), การตรวจสอบยอดคงเหลือและปริมาณการใช้, สถิติคลังความรู้ เอกสาร API เปิดดูได้ที่ `/openapi/docs` บนเว็บไซต์ที่เข้าใช้งานผ่านเบราว์เซอร์

### 10.2 Webhook Callback

ลงทะเบียน URL Callback และสมัครรับเหตุการณ์ (เช่น `translation.completed`) เมื่อการแปลเสร็จสิ้น แพลตฟอร์มจะเป็นฝ่ายส่งการแจ้งเตือนไปยังระบบของคุณอัตโนมัติ; รองรับการตรวจสอบลายเซ็น (X-Signature), ส่งทดสอบ, ดูประวัติการส่งและลองส่งใหม่

### 10.3 SDK อย่างเป็นทางการและปลั๊กอิน

หน้า «SDK อย่างเป็นทางการ» มีคำแนะนำการติดตั้งและทางดาวน์โหลดสามช่องทาง:

| แพลตฟอร์ม | วิธีการได้รับ | การใช้ |
|----|----------|------|
| Python | ดาวน์โหลดไฟล์ `.whl` (หรือซอร์ส `.tar.gz`) จากหน้า "SDK อย่างเป็นทางการ" ของเว็บไซต์นี้ แล้วใช้ `pip install <ไฟล์ที่ดาวน์โหลด>` (โฮสต์ที่ `/sdk/` ของเว็บไซต์นี้ ไม่ได้เผยแพร่บน registry ภายนอก) | แปลแบบโปรแกรม งานชุด  |
| TypeScript | ดาวน์โหลดไฟล์ `.tgz` จากหน้า "SDK อย่างเป็นทางการ" ของเว็บไซต์นี้ แล้วใช้ `npm install <ไฟล์ที่ดาวน์โหลด>` (โฮสต์บน `/sdk/` ของเว็บไซต์นี้) | การเชื่อม Node/ฟรอนต์เอนด์  |
| Java | แจกซอร์สโค้ดผ่าน Maven | เชื่อมต่อกับระบบในองค์กร |
| ส่วนขยายแปลคำในเบราว์เซอร์ | ดาวน์โหลด zip ในหน้านั้น (ไม่มีช่องทางผ่าน app store) | เลือกข้อความบนเว็บเพจใด ๆ → กดปุ่ม «译» ที่ลอยขึ้น → ดูคำแปลในฟองพร้อมคัดลอก; ทางลัด Alt+Shift+T (macOS ใช้ Alt+T) |
| แอปพลิเคชันเสริม Word | เว็บไซต์มี manifest ของแอปพลิเคชัน ใช้ «แทรก → รับแอปพลิเคชันเสริม → อัปโหลดแอปพลิเคชันเสริมของฉัน» ใน Word เพื่อ side-load | แปลข้อความที่เลือกใน Word แล้วแทรกกลับเข้าเอกสาร |
| ปลั๊กอิน VS Code | vscode-extension ใน repository | แปลข้อความที่เลือก ณ จุดนั้นในตัวแก้ไข lookup คำศัพท์ |

**การตั้งค่าส่วนขยาย/แอปพลิเคชันเสริม** (popup ของส่วนขยายและแผงงาน (task pane) ของ Word ใช้ตรรกะเดียวกัน): กรอก**ที่อยู่บริการ** (URL รากของเว็บไซต์), **API Key** (ออกใน 10.1 ของบทนี้), **ภาษาเป้าหมาย**, **โหมดการแปล** (รวดเร็ว/มืออาชีพ) ก็ใช้งานได้ คำศัพท์และความจำการแปลสอดคล้องกับภายในเว็บ

⚠ หากหลังอัปเดตส่วนขยายแล้วสไตล์ไม่เปลี่ยน: ใช้ zip ใหม่เขียนทับ**ไดเรกทอรีเดิม** แล้วไปที่ `chrome://extensions` กดปุ่ม**โหลดอีกครั้ง (Reload)** บนการ์ดของส่วนขยายนั้น

### 10.4 ขอบเขตของผู้ดูแลแผนก

หากผู้ดูแลแผนกต้องการเชื่อมต่อ API กรุณาติดต่อผู้ดูแลองค์กรเพื่อออก Key; เมนู «การเรียกใช้จากภายนอก» จะไม่แสดงต่อผู้ดูแลแผนก

## 11. การแจ้งเตือน ข้อเสนอแนะ และผู้ช่วย AI

### 11.1 ศูนย์ประกาศ (ทุกบุคคล)

กริ่งบนแถบบน: สำรวจข้อความที่ยังไม่อ่านทุก ~30 วินาที เปิดดูรายการได้ทันที (การแปลคำขอเสร็จ ผลอนุมัติ การแจ้งเตือนลดรูปแบบการส่งมอบ ฯลฯ) ทำเครื่องหมายอ่านแล้วรายชิ้นหรือทั้งหมดได้

### 11.2 ส่งและจัดการข้อเสนอแนะ

- **ทุกบุคคล**: ที่หน้ารายละเอียดคำขอที่เสร็จแล้ว «ส่งข้อเสนอแนะ» อธิบายย่อหน้าที่มีปัญหาและความคาดหวัง
- **ผู้ดูแลแผนก/ผู้ดูแลองค์กร**: ดูข้อเสนอแนะของ tenant นี้และ**ตอบกลับ**ได้ที่ «ข้อเสนอแนะ / การอนุมัติ» ในหน้าผู้ดูแล; แท็บ «โต๊ะอนุมัติ» ในหน้าเดียวกันใช้จัดการคำขอที่รออนุมัติ (อนุมัติ/ตีกลับ)
- แผง «ภาพรวม» (ผู้ดูแลแผนกขึ้นไป): ดูแดชบอร์ดปฏิบัติการและรายละเอียดการใช้ขององค์กรนี้ (รายละเอียดการใช้ส่งออก CSV ได้)

### 11.3 วิดเจ็ตผู้ช่วย AI (ทุกบุคคลและผู้มาเยือน)

ปุ่ม «ผู้ช่วย AI» มุมขวาล่างของหน้า เรียกบทสนทนาได้ทุกเมื่อ: สอบถามผลิตภัณฑ์ นำทางฟีเจอร์ ไปหน้าปลายทางด่วน รีโหลดหน้าบทสนทนาไม่หาย (แคชในเครื่อง → กู้ประวัติคลาวด์อัตโนมัติ)

## 12. คำถามที่พบบ่อย

**Q1: ปุ่มแปลกดไม่ทำงาน / แจ้งว่าโควตาไม่พอ?**
ยอดคงเหลือปัจจุบันหรืองบแผนกใช้หมดแล้ว ผู้ใช้ทั่วไปโปรดติดต่อผู้ดูแลองค์กรของคุณ; ผู้ดูแลดูรายละเอียดการใช้ได้ในหน้าผู้ดูแล

**Q2: ทางเข้าแปลไฟล์อยู่ที่ไหน ทำไมกล่องแชทอัปโหลดไฟล์แนบไม่ได้แล้ว?**
การแปลไฟล์ใช้ «คำขอการแปล → ไฟล์» แต่เพียงผู้เดียว กล่องบทสนทนาให้บริการเฉพาะการแปลข้อความล้วน

**Q3: PDF ถูกปฏิเสธการแปล?**
PDF ที่เกิน 40MB หรือ 120 หน้า ต้องแปลงเป็น docx ก่อนแล้วจึงสร้างคำขอ; PDF แบบสแกน (ภาพเต็มหน้า) ยังไม่รองรับ

**Q4: ทำไมคำแปลไม่ตรงกับตารางคำศัพท์ของฉัน?**
ตรวจสอบว่าคำศัพท์นำเข้าคลังความรู้แล้วและแพ็กมองเห็นได้จากแผนกของคุณหรือไม่ (บทที่ 7); เนื้อหาที่จะเผยแพร่อย่างเป็นทางการกรุณาเลือกโหมด «พิสูจน์อักษรมืออาชีพ»

**Q5: docx ที่ส่งมอบมีเลย์เอาต์ต่างจากต้นฉบับ?**
«โหมดคืนรูปแบบไฟล์เดิม» รักษาเลย์เอาต์ไว้ได้เป็นส่วนใหญ่; บางเลย์เอาต์ซับซ้อนจะลดระดับเป็นการส่งมอบข้อความ .md พร้อมแจ้งในข้อความภายในระบบ สามารถดาวน์โหลด .md แล้วทบทวนด้วยแก้ไขแบบเทียบเคียง หรือส่งข้อเสนอแนะได้

**Q6: แปลเสร็จแล้ว ตัวเลขยอดคงเหลือไม่เปลี่ยน?**
ข้อมูลการนับปริมาณการใช้จะถูกบันทึกลงฐานข้อมูลแบบซิงโครนัสทันทีที่แปลเสร็จ หากหน้ายังไม่รีเฟรช กรุณากดรีเฟรชหนึ่งครั้ง; หากยังผิดปกติอยู่ให้ส่งข้อเสนอแนะ

**Q7: เปลี่ยนไปใช้มือถือ/แท็บเล็ตได้ไหม?**
เข้าผ่านเบราว์เซอร์โดยตรงได้เลย อินเทอร์เฟซปรับตามจอแคบเอง; ส่วนขยายและแอปพลิเคชันเสริมออกแบบสำหรับเดสก์ท็อปเป็นหลัก

**Q8: ข้อความบนหน้าจอแสดงผลไม่ครบหรือจัดวางผิดปกติ (เช่นภาษาอาหรับ)?**
สลับไปภาษาอื่นก่อนเพื่อยืนยันว่าเป็นที่คำเดียวผิดปกติ จากนั้นส่งข้อเสนอแนะพร้อมภาพหน้าจอผ่านช่องทางรับข้อเสนอแนะ
