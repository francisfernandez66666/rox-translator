## 一、產品概覽

**能言（LangCross）** 是面向企業與團隊的 AI 翻譯協作平台，把三類翻譯方式和一個企業語料資產體系整合在一起：

| 能力 | 說明 |
|------|------|
| 即時翻譯 | 對話框式文字翻譯，輸入即譯，支援一次翻往多個目標語言 |
| 翻譯工單 | 上傳 docx / pptx / xlsx / pdf 等檔案，走「建單 → 核準 → 翻譯 → 交付」完整流程，按原格式交付譯文檔案 |
| 對照編輯 | 原文/譯文雙欄逐段對照，可修改、核準、駁回並留批註 |
| 知識庫 / 翻譯記憶（KB/TM） | 企業術語、雙語句對、品牌固定譯名進入知識庫，翻譯時自動命中並統一口徑 |

主要特點：

- **40+ 語言互譯**，介面本身提供 12 種語言（簡體中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Русский、العربية、ไทย），阿拉伯語介面為從右到左排版。
- **雙翻譯模式**：「快速」輕量高效；「專業校對」帶知識庫術語校準、品質評估與硬性校驗閘門，適合對外發布內容。
- **企業隔離**：每個租戶的資料、知識庫、成員相互隔離；組織內再按部門隔離知識庫與預算。
- **多端一致**：除網頁端外，提供瀏覽器劃詞擴充功能、Word 增益集、VS Code 外掛和開放 API/SDK，譯文口徑與網頁端同源。

## 二、快速上手

### 2.1 登入

打開企業分配給你的存取網址（平台網址或企業專屬子網域），在登入頁輸入**使用者名稱**和**密碼**即可。

- 忘記密碼：點擊「找回密碼」，透過綁定電子郵件接收驗證碼重設。
- 企業已啟用統一身分（SSO）時，登入頁會出現「或使用企業身分源登入」按鈕，點擊後用企業帳號直接登入。
- 首次登入：若管理員為你開通帳號時未設定電子郵件，系統會彈出不可關閉的「請綁定電子郵件」視窗，請先完成綁定；批次開通的帳號首次登入會被要求「首次登入請修改密碼」。

### 2.2 註冊 / 加入企業

兩種進入方式：

- **加入既有企業**：註冊時填寫組織編碼 + **邀請碼**（必填，向貴企業管理員索取），即加入對應部門，成為一般使用者。透過企業專屬子網域（`企業編碼.網域`）存取註冊頁時，企業資訊會自動帶入，此入口只能註冊為該企業一般成員。
- **建立新企業**：邀請碼留空註冊即建立新組織，註冊人成為該組織的組織管理員，可繼續邀請同事加入（見第九章）。

註冊流程支援 AI 助理引導：選擇帳號類型（個人/企業）、企業身分（管理員建企業 / 成員憑邀請碼加入）、產業與職業角色、填寫帳號資訊，按提示逐步完成即可，支援返回上一步。選擇「個人」即開通個人版，功能邊界見 [3.1 個人版使用者](#31-個人版使用者)。

### 2.3 認識介面

登入後進入工作台，主要區域：

| 區域 | 內容 |
|------|------|
| 頂欄 | 三個工作台頁籤：**即時翻譯**、**翻譯工單**、**對照編輯**；右側為積分餘額徽標、通知鈴鐺、語言切換、帳號選單；部門管理員及以上額外可見「上傳知識庫」按鈕與「進入管理後台」入口 |
| 「更多」抽屜 | 我的帳號等自助頁入口與頁尾 |
| 主內容區 | 目前頁籤的工作介面 |
| 右下「AI 助手」 | 隨時可喚起的智慧助理小工具（見第十一章） |

- **切換介面語言**：頂欄語言下拉，選項各以本語言自稱（如「日本語」「한국어」）；選擇後全站立即生效，瀏覽器首次存取會自動按系統語言偵測。
- **行動端**：手機/平板瀏覽器可直接使用，窄螢幕下後台側欄自動轉為抽屜選單。
- **帳號選單**（右上角頭像）：進入管理後台（部門管理員及以上）/ 返回工作台、修改密碼、修改電子郵件、我的職業角色、登出。

### 2.4 完成第一次翻譯

1. 在「即時翻譯」輸入框貼上要翻譯的文字；
2. 確認來源語言（預設「自動偵測」），點目標語言選擇器選好一種或多種語言（候選按「知識庫語言 / 其他語言」分組）；
3. 選擇模式（快速 / 專業校對），點擊「翻譯」；
4. 譯文以對話氣泡形式逐段上屏，可複製譯文、檢視原文、繼續追問修改風格。

檔案翻譯請看第五章。

## 三、角色與權限

租戶內共三級角色，權限逐級擴大：

| 角色 | 誰能用 | 可見功能 |
|------|--------|----------|
| **一般使用者** | 所有成員 | 即時翻譯、翻譯工單（建單/檢視/下載）、對照編輯、通知中心、AI 助手、我的帳號；介面語言、職業角色設定 |
| **部門管理員** | 由組織管理員指定 | 一般使用者全部功能 + 管理後台基礎選單：**總覽**（含用量明細）、**反饋/核準**（核準工單、回覆反饋）、**知識庫**（本部門包/跨部門包）、頂欄「上傳知識庫」 |
| **組織管理員** | 每企業至少一名（建立者或被授權人） | 部門管理員全部功能 + **組織與成員**（部門樹、成員、邀請碼、預算）、**外部調用**（API Key、Webhook、SDK）、**知識庫**（組織包/部門包/跨部門包全類型）、品牌名（固定譯名）維護、SCIM 組織同步設定 |

說明：

- 本手冊只覆蓋上述租戶內角色；平台營運功能不在範圍內。
- 「反饋/核準」頁籤中帶有「記憶審核」「完成反饋歸檔」等字樣的操作屬於平台側流程，租戶介面不出現，無需關注。
- 權限疑問請聯絡貴企業的組織管理員。

### 3.1 個人版使用者

註冊時選擇「個人」帳號類型（不需要組織編碼和邀請碼），即開通**個人版**——頂欄身分徽標顯示「個人版」，帳號歸你自己管理，沒有企業成員與部門概念。

個人版可用的功能：

| 功能 | 說明 |
|------|------|
| 三大工作台 | 即時翻譯、翻譯工單、對照編輯，與企業版完全一致 |
| 管理後台 | 頂欄帳號選單可進入：**知識庫**（上傳維護自己的術語表，僅自己可見可用）、**外部調用**（自助簽發 API Key，配套瀏覽器擴充功能/Word 增益集/SDK 使用）、**總覽**（自己的用量明細） |
| 我的職業角色 | 同企業版，按崗位自動裝配角色包（見 7.5） |
| 自助頁 | 更多 → 我的帳號；修改密碼、修改電子郵件、通知中心、註銷帳號 |

與企業版的差異：

- **沒有「組織與成員」**：不存在部門、成員開通、部門預算等管理需求；
- **工單沒有核準環節**：建立的翻譯工單直接進入排隊執行，不會停在「待核準」；
- 沒有企業專屬子網域和組織共享知識庫；產業包、語言文化包等平台通用知識庫照常自動生效。

個人版額度或餘額不足時，按介面提示處理即可。

## 四、即時翻譯（工作台）

「即時翻譯」是登入後的預設頁，一張整屏對話框，歷史在上、輸入貼底。

### 4.1 輸入區（框腳工具列）

一張輸入卡，內含單行自適應輸入框和一行工具列：

| 控件 | 說明 |
|------|------|
| 原文·自動偵測 | 選擇來源語言，預設自動偵測 |
| 目標語言 | 點開選擇器；語種按「知識庫語言 / 其他語言（AI翻譯）」分組，「更多語言…」可搜尋全部語種；已選語種以標籤顯示，超過 3 個折疊為「+n」，點開可逐個移除 |
| 專業校對 / 快速 | 翻譯模式。快速＝AI 初翻+校對，輕量高吞吐；專業校對＝知識庫術語校準 + 品質評估 + 硬性校驗閘門全流程，適合正式發布內容 |
| 縮譯 | 勾選後譯文按長度約束收斂，適合標題、按鈕文字等有字數限制的場景 |
| 翻譯（主按鈕） | 開始翻譯；產生中可點「停止生成」 |

預估消耗會在送出前顯示。餘額不足或額度用盡時介面會提示，並說明聯絡管理員處理。

### 4.2 對話與結果

- 原文與譯文在同一氣泡框內上下呈現，譯文串流逐段上屏。
- 每條譯文標註來源方式：**精確命中 / 模糊匹配 / 語義相似**（來自知識庫）或 **線上翻譯**（AI 產生）；命中知識庫術語時高亮顯示。
- 氣泡操作：複製譯文、檢視原文；可繼續送出指令讓 AI 調整語氣、風格，上下文會延續。
- 翻譯過程的環節（術語檢索 → 機器翻譯 → 術語校準 → 翻譯完成）在介面上有階段提示。

### 4.3 會話管理

對話框頂部提供：

- **搜尋本會話訊息**（快捷鍵 Ctrl/⌘+K）；
- **匯出會話記錄**（Markdown 檔案）；
- **清空對話**。

### 4.4 用量顯示

介面上的消耗量統一以「積分」顯示，並折算「約可翻句數」。輸入區附近常顯：餘額（積分 ≈ 句數）、今日消耗、部門預算進度（掛了部門且有預算時）。

## 五、翻譯工單（檔案翻譯）

所有**檔案翻譯**都在「翻譯工單」頁發起，走完整流程：建單 → （按企業設定）核準 → 翻譯 → 交付。

### 5.1 建立工單

點擊「建立翻譯工單」，選擇「文字」或「檔案」頁籤：

- **文字**：貼上長文字，選目標語言與模式，直接建單。
- **檔案**：上傳一個或多個檔案，可一次勾選多種目標語言（產物打包為 zip 下載）。

關鍵欄位：

| 欄位 | 說明 |
|------|------|
| 交付方式 | **還原排版模式**（預設）：按原格式交付譯文檔案（版式還原），另附純文字 .md 兜底產物；**僅純文字**：本地擷取正文翻譯，交付譯文 .md，不承諾版式（適合老格式 doc/ppt/xls、odt/epub/rtf 等） |
| 模式 | 快速（無知識庫）/ 專業校對 |
| 目標語言 | 可多選 |
| 預計消耗 | 建單前顯示「預計消耗 {n} 句 · 餘額 {n} 句」 |

檔案格式支援：

| 類別 | 格式 | 交付 |
|------|------|------|
| 可還原版式 | docx、pptx、xlsx、pdf、txt、csv、md | 同格式譯文檔案 |
| 對照表交付 | srt、vtt、json、yaml 等 | 原文/譯文對照 xlsx |
| 僅純文字 | doc、ppt、xls 系老格式、odt/ods/odp、rtf、epub | 譯文 .md |

限制與說明：

- 單次工單檔案數量與大小有上限；PDF 超過 40MB 或 120 頁會友善拒絕並提示先轉為 docx。
- 掃描版 PDF（純圖片）不支援；圖片內的文字按產品策略不翻譯。
- 版式回寫萬一失敗，該檔案自動降級為 .md 交付並站內訊息通知，不會整單失敗。

### 5.2 工單狀態與流轉

「我的工單」列表可按狀態篩選，狀態含義：

```
排隊中 → 翻譯中 → 已完成
待核準 → 已核準 → 翻譯中 …    （企業開啟核準時）
        └→ 已駁回
任意進行中狀態 → 已取消
```

- 進行中可點「取消」；已結束的可「刪除」。
- 若貴企業開啟了核準，工單先落在「待核準」，由部門管理員/組織管理員在後台「反饋/核準」的審核工作台核準（已核準）或駁回（已駁回，附原因）。

### 5.3 檢視進度與下載

點開工單看「執行進度」步驟條，環節包括：解析擷取 → 知識庫匹配 → AI 初譯 → 專業校對 → 硬閘校驗 → 文化檢查 → 回寫檔案 等（按模式與檔案類型顯示）。

- 完成後點「下載」取譯文；純文字兜底可用「僅下載譯文文字（.md）」。
- 多語言/多檔案任務下載即為 zip 包。

### 5.4 質檢報告

專業校對模式的已完成工單帶有「質檢報告」區塊：整體結論（質檢通過 / 質檢未通過 / 質檢存疑）、機器評估分（滿分 100）及分段說明。對結果有異議可在工單詳情「提交意見反饋」，管理員會在後台看到並回覆。

### 5.5 對照編輯銜接

已完成工單可一鍵進入「對照編輯」逐段複核，見下一章。

## 六、對照編輯

「對照編輯」用於對工單譯文做人工終審：

1. 從工單詳情跳轉，或在「對照編輯」頁按工單 ID/工單號「載入」；
2. 左欄原文、右欄譯文逐段對照，知識庫術語在原文側高亮；
3. 每段可：**核準** / **駁回**（填寫批註/駁回原因）/ 直接修改譯文；
4. 點「儲存」留存人工修訂。

人工確認的高品質句對是翻譯記憶的優質來源——企業知識庫管理員可將其整理匯入（見第七章）。

## 七、知識庫與翻譯記憶

知識庫（KB）讓翻譯「懂你的企業」：統一術語、重複使用已確認譯文、鎖死合規表述。

### 7.1 四層內容

| 層 | 內容 | 典型用途 |
|----|------|----------|
| L1 術語 | 術語對照（含品牌名、產品名固定譯法） | 強制統一用詞 |
| L2 翻譯記憶（TM） | 已確認的原文/譯文句對 | 整句或片段直接重複使用 |
| L3 安全句 | 禁用詞 / 取代對 / 風格規範 | 語言文化硬閘校驗，譯文中自動攔截或取代 |
| L4 碎片 | 零散表達、句式參考 | 模糊匹配的例句參考 |

翻譯時的命中優先序：本組織鏈上的部門包（本部門→上級→根，就近覆蓋）＞ 組織包 ＞ 產業/語言文化包；跨部門共享包需管理員開啟後作為回退層參與。

### 7.2 誰可以維護什麼

| 操作 | 所需角色 |
|------|----------|
| 頂欄「上傳知識庫」（識別檔案 → 選包 → 匯入） | 部門管理員及以上 |
| 建立/維護**部門包**、**跨部門包** | 部門管理員及以上 |
| 建立/維護**組織包（本企業）**、跨部門共享總開關、包級授權 | 組織管理員 |
| 維護「品牌名」（品牌/產品固定譯名） | 可存取知識庫面板的角色 |
| 匯入雙語語料 / TMX、匯出 TMX | 部門管理員及以上 |
| 維護「語言文化規範（安全句）」 | 部門管理員及以上 |

### 7.3 包類型

- **組織包（本企業）**：全企業生效；
- **部門包（本部門）**：僅本部門及組織鏈內可見，實現部門級術語隔離；
- **跨部門包（共享）**：預設不外借，包級「跨部門共用·開/關」+ 企業策略開關共同決定是否對其他部門生效。

### 7.4 匯入方式

進入管理後台「知識庫」面板（部門管理員及以上）：

- **檔案匯入**：上傳術語表/文件，系統識別後寫入所選包；
- **雙語語料 / TMX 匯入**：批次寫入翻譯記憶，相容主流 CAT 工具（Trados/memoQ 等）匯出的 TMX；
- **匯出 TMX**：把企業記憶帶回原有工具鏈。

平台側還會按產業自動裝配通用「產業包 / 語言文化包」，無需企業維護，翻譯時自動生效。

### 7.5 我的職業角色（全員）

帳號選單 →「我的職業角色」：從預設角色詞典（15+ 職業）中選擇自己的崗位角色。翻譯時系統自動裝配對應角色包，讓術語與語氣更貼近你的工作場景。

## 九、組織與成員管理（組織管理員）

入口：帳號選單 →「進入管理後台」→ 左側「組織與成員」。

### 9.1 組織結構

- **新建組織 / 新建部門**：維護企業多級組織樹；支援重命名。
- **部門預算**：為部門「分配月度預算」，控制該部門成員的翻譯用量；成員的介面會顯示部門預算進度。

### 9.2 成員帳號

「成員帳號」頁管理企業全部帳號：

- **開通使用者**：單一建立成員，指定角色（一般使用者 / 部門管理員 / 組織管理員）與所屬組織；
- **Excel 批量匯入使用者**：一次開通多名成員，初始密碼經電子郵件通知，成員首次登入被要求修改密碼；
- 對既有成員：**重設密碼**、**啟用/停用**帳號、調整角色與組織歸屬。

### 9.3 邀請員工

「邀請員工」頁產生**邀請碼**（可多個、可指定加入的組織層級）。把組織編碼 + 邀請碼告知同事，其在註冊頁填寫即加入對應部門。

### 9.4 SCIM 組織同步（可選）

「更多 → 我的帳號」中的 SCIM 卡：企業使用 Okta、Entra ID 等身分源時，可取得 SCIM 端點與權杖完成成員自動開通/同步；啟用後員工可走登入頁的 SSO 按鈕免密登入。

## 十、外部調用與整合（組織管理員）

入口：管理後台 →「外部調用」。三個子頁：**開放 API**、**回調通知**、**官方 SDK**。

### 10.1 開放 API Key

- **簽發 API Key**：建立時明文完整顯示**僅一次**，請立即儲存；
- 支援對 Key **啟用/停用、輪替、設定每日限額、刪除**；
- Key 綁定本企業租戶與積分口徑，用 API 產生的消耗與網頁端同帳。

開放 API 提供：非同步翻譯任務（建立 → 輪詢 → 下載，支援多檔案多語言，產物可打包 zip）、同步短文翻譯（≤5000 字元、≤5 語言）、餘額與用量查詢、知識庫統計。介面文件可在瀏覽器存取站點的 `/openapi/docs` 檢視。

### 10.2 Webhook 回調

登記回調 URL 並訂閱事件（如 `translation.completed`），翻譯完成時平台主動通知貴方系統；支援簽章驗證（X-Signature）、傳送測試、檢視投遞歷史與重試。

### 10.3 官方 SDK 與外掛

「官方 SDK」頁提供三端安裝指引與下載入口：

| 端 | 取得方式 | 用途 |
|----|----------|------|
| Python | `pip install langcross-translator` | 程式化翻譯、批次任務 |
| TypeScript | `npm i @langcross/translator-sdk` | Node/前端整合 |
| Java | Maven 原始碼分發 | 企業內系統對接 |
| 瀏覽器劃詞擴充功能 | 該頁下載 zip（無應用商店通路） | 任意網頁選取文字→點浮出「譯」按鈕→氣泡看譯文並複製；快捷鍵 Alt+Shift+T（macOS 為 Alt+T） |
| Word 增益集 | 站點提供增益集清單，Word「插入 → 取得增益集 → 側載我的增益集」側載 | 在 Word 內翻譯選取文字並插回文件 |
| VS Code 外掛 | 倉庫內 vscode-extension | 編輯器內選取文字就地翻譯、查術語 |

**擴充功能/增益集設定**（劃詞擴充功能 popup 與 Word 窗格相同邏輯）：填**服務地址**（站點根地址）、**API Key**（本章 10.1 簽發）、**目標語言**、**翻譯模式**（快速/專業校對）即可使用，術語與翻譯記憶與站內一致。

⚠ 擴充功能升級後若樣式未變：用新 zip 覆蓋**同一目錄**，並到 `chrome://extensions` 點該擴充功能卡片上的**重新整理**按鈕。

### 10.4 部門管理員的邊界

部門管理員如需 API 整合，請聯絡組織管理員開通 Key；「外部調用」選單不對部門管理員顯示。

## 十二、常見問題

**Q1：翻譯按鈕按不動 / 提示額度不足？**
目前餘額或部門預算已用完。一般使用者請聯絡企業管理員處理；管理員可在管理後台檢視用量明細。

**Q2：檔案翻譯入口在哪？對話框怎麼不能傳附件了？**
檔案翻譯統一走「翻譯工單 → 檔案」，對話框只做純文字翻譯。

**Q3：PDF 翻譯被拒絕？**
超過 40MB 或 120 頁的 PDF 請先轉為 docx 再建單；掃描版 PDF（整頁圖片）暫不支援。

**Q4：為什麼譯文和我的術語表不一致？**
檢查術語是否已匯入知識庫且包對本部門可見（第七章）；正式內容請選用「專業校對」模式。

**Q5：交付的 docx 版式和原文有出入？**
「還原排版模式」絕大多數情況保持版式；個別複雜版式會降級為 .md 文字交付並站內訊息通知。可下載 .md 後用對照編輯複核，或提交反饋。

**Q6：剛翻譯完，餘額數字沒變？**
計量在翻譯完成瞬間同步寫庫，若頁面未重新整理請手動重新整理一次；仍異常再提交反饋。

**Q7：換手機/平板能用嗎？**
瀏覽器直接存取即可，介面自適應窄螢幕；擴充功能與增益集以桌面端為主。

**Q8：介面文字顯示不全或排版怪（阿拉伯語等）？**
先切換其他語言確認是否為個別詞條，然後透過反饋管道提交截圖。
