> 화면 명칭은 제품 실제 표시 문안을 기준으로 합니다; 본 문서와 다소 차이가 있더라도 화면을 기준으로 하세요.

## 1. 제품 개요

**LangCross（能言）** 는 기업과 팀을 위한 AI 번역 협업 플랫폼으로, 세 가지 번역 방식과 하나의 기업 언어 자산 체계를 하나로 통합했습니다:

| 기능 | 설명 |
|------|------|
| 실시간 번역 | 대화창 방식의 텍스트 번역, 입력 즉시 번역하며 한 번에 여러 목표 언어로 번역 가능 |
| 번역 티켓 | docx / pptx / xlsx / pdf 등 파일을 업로드하여 「생성 → 승인 → 번역 → 전달」 전체 플로우를 진행하고, 원본 서식의 번역 파일로 전달 |
| 대조 편집 | 원문/번역문 2단으로 단락별 대조: 수정, 승인, 반려 및 코멘트 작성 가능 |
| 지식베이스 / 번역 메모리 (KB/TM) | 기업 용어, 이중 언어 문장 쌍, 브랜드 고정 역명을 지식베이스에 등록하면 번역 시 자동으로 적용되어 표현이 통일됨 |

주요 특징:

- **40개 이상 언어 상호 번역**, 인터페이스 자체는 12개 언어를 제공합니다(简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Русский、العربية、ไทย), 아랍어 인터페이스는 우측에서 좌측으로(RTL) 조판됩니다.
- **두 가지 번역 모드**: 「신속」은 가볍고 고효율; 「전문 교정」은 지식베이스 용어 교정, 품질 평가 및 하드 검증 게이트를 갖추고 있어 대외 발표 내용에 적합합니다.
- **기업 격리**: 각 테넌트의 데이터, 지식베이스, 멤버가 서로 격리되며; 조직 내에서는 다시 부서별로 지식베이스와 예산이 격리됩니다.
- **멀티 디바이스 일치**: 웹 외에도 브라우저 선택 번역 확장 프로그램, Word 애드인, VS Code 플러그인 및 Open API/SDK를 제공하며, 번역 문안은 웹과 동일합니다.

## 2. 빠른 시작

### 2.1 로그인

회사에서 할당된 접근 주소(플랫폼 주소 또는 기업 전용 서브 도메인)를 열고, 로그인 페이지에 **사용자 이름**과 **비밀번호**를 입력하면 됩니다.

- 비밀번호 찾기: 「비밀번호를 잊으셨나요?」를 클릭하여 바인딩된 이메일로 전송된 인증 코드로 재설정하세요.
- 기업이 통합 신원(SSO)을 활성화한 경우, 로그인 페이지에 「또는 기업 신원 공급자로 로그인」 단추가 표시되는데, 클릭하면 기업 계정으로 바로 로그인할 수 있습니다.
- 첫 로그인: 관리자가 계정을 만들 때 이메일을 설정하지 않았다면, 닫을 수 없는 「이메일 바인딩」 창이 팝업되니 먼저 바인딩을 완료하세요. 일괄 생성된 계정은 첫 로그인 시 「첫 로그인입니다. 비밀번호를 변경하세요」를 요구받습니다.

### 2.2 등록 / 기업 가입

두 가지 진입 방식:

- **기존 기업 가입**: 등록 시 조직 코드 + **초대 코드**(필수, 귀사 관리자에게 문의)를 입력하면 해당 부서에 가입되어 일반 사용자가 됩니다. 기업 전용 서브 도메인(`기업코드.도메인`)으로 등록 페이지에 접근하면 기업 정보가 자동 입력되며, 이 진입구에서는 해당 기업의 일반 멤버만 등록할 수 있습니다.
- **새 기업 생성**: 초대 코드를 비우고 등록하면 새 조직이 생성되고, 등록자가 해당 조직의 조직 관리자가 되어 계속 동료를 초대할 수 있습니다(9장 참조).

등록 플로우에는 AI 어시스턴트 안내를 지원합니다: 계정 유형 선택(개인/기업), 기업 신원(관리자가 기업 생성 / 멤버가 초대 코드로 가입), 업종 및 직무 역할 선택, 계정 정보 입력 순, 안내에 따라 단계별로 완료하면 되며 이전 단계로 돌아갈 수 있습니다. 「개인」을 선택하면 개인 버전가 개설되고, 기능 범위는 [3.1 개인 버전 사용자](#31-개인-버전-사용자)를 참고하세요.

### 2.3 화면 익히기

로그인 후 워크스페이스로 진입하며, 주요 영역은 다음과 같습니다:

| 영역 | 내용 |
|------|------|
| 상단 바 | 세 개의 워크스페이스 탭: **실시간 번역**, **번역 티켓**, **대조 편집**; 우측에는 포인트 잔액 배지, 알림 벨, 언어 전환, 계정 메뉴가 있고, 부서 관리자 이상은 「지식베이스 업로드」 단추와 「관리 콘솔로」 진입구도 볼 수 있습니다 |
| 「더보기」 서랍 | 내 계정 등 셀프 서비스 페이지 진입구와 푸터 |
| 메인 콘텐츠 영역 | 현재 탭의 작업 화면 |
| 우측 하단 「AI 어시스턴트」 | 언제든 호출 가능한 지능형 어시스턴트 위젯(11장 참조) |

- **인터페이스 언어 전환**: 상단 바 언어 드롭다운에서 각 언어가 자기 언어로 표기됩니다(예: 「日本語」「한국어」); 선택 즉시 전 사이트 언어가 반영되며, 브라우저 첫 방문 시 시스템 언어를 자동으로 감지합니다.
- **모바일**: 스마트폰/태블릿 브라우저에서 바로 사용할 수 있고, 좁은 화면에서는 관리 패널의 사이드바가 자동으로 서랍 메뉴로 전환됩니다.
- **계정 메뉴**(우측 상단 아바타): 관리 콘솔로(부서 관리자 이상) / 워크스페이스로 돌아가기, 비밀번호 변경, 이메일 변경, 내 직무 역할, 로그아웃.

### 2.4 첫 번역 완료하기

1. 「실시간 번역」 입력창에 번역할 텍스트를 붙여넣습니다;
2. 원본 언어(기본값 「자동 감지」)를 확인하고, 목표 언어 선택기를 열어 하나 또는 여러 언어를 선택합니다(후보군은 「지식베이스 언어 / 기타 언어」로 그룹화됨);
3. 모드(신속 / 전문 교정)를 선택하고 「번역」을 클릭합니다;
4. 번역문이 대화 말풍선 형태로 단락별로 화면에 표시되며, 번역문 복사, 원문 보기, 스타일 수정을 위한 후속 질의가 가능합니다.

파일 번역은 5장을 참고하세요.

## 3. 역할 및 권한

테넌트 내에는 모두 세 단계의 역할이 있으며, 권한이 단계별로 커집니다:

| 역할 | 대상 | 표시 기능 |
|------|--------|----------|
| **일반 사용자** | 모든 멤버 | 실시간 번역, 번역 티켓(생성/보기/다운로드), 대조 편집, 알림 센터, AI 어시스턴트, 내 계정; 인터페이스 언어, 직무 역할 설정 |
| **부서 관리자** | 조직 관리자가 지정 | 일반 사용자의 모든 기능 + 관리 콘솔 기본 메뉴: **개요**(사용량 명세 포함), **피드백/승인**(티켓 승인, 피드백 답변), **지식베이스**(해당 부서 패키지/부서 간 패키지), 상단 바 「지식베이스 업로드」 |
| **조직 관리자** | 기업마다 최소 1명(생성자 또는 위임자) | 부서 관리자의 모든 기능 + **조직 및 멤버**(부서 트리, 멤버, 초대 코드, 예산), **외부 호출**(API Key, Webhook, SDK), **지식베이스**(조직 패키지/부서 패키지/부서 간 패키지 전 유형), 브랜드명(고정 역명) 유지보수, SCIM 조직 동기화 설정 |

설명:

- 본 매뉴얼은 상기 테넌트 내 역할만 다루며, 플랫폼 운영 기능은 범위에 포함되지 않습니다.
- 「피드백/승인」 탭에서 「메모리 심사」「피드백 아카이브 완료」 등 문구가 표시된 작업은 플랫폼 측 프로세스에 속하며, 테넌트 화면에는 표시되지 않으므로 신경 쓸 필요가 없습니다.
- 권한에 대한 문의는 귀사의 조직 관리자께 연락하세요.

### 3.1 개인 버전 사용자

등록 시 「개인」 계정 유형을 선택하면(조직 코드와 초대 코드 불필요) **개인 버전**가 개설됩니다—상단 바 신원 배지에 「개인 버전」가 표시되고, 계정은 본인만 관리하며 기업 멤버나 부서의 개념이 없습니다.

개인 버전에서 사용할 수 있는 기능:

| 기능 | 설명 |
|------|------|
| 3대 워크스페이스 | 실시간 번역, 번역 티켓, 대조 편집, 기업 버전과 완전히 동일 |
| 관리 콘솔 | 상단 바 계정 메뉴에서 진입: **지식베이스**(용어표 업로드 및 유지보수, 본인만 표시·사용 가능), **외부 호출**(API Key 셀프 발급, 브라우저 확장 프로그램/Word 애드인/SDK와 함께 사용), **개요**(본인 사용량 명세) |
| 내 직무 역할 | 기업 버전과 동일, 직무별 사전 역할 패키지 자동 적용(7.5 참조) |
| 셀프 서비스 페이지 | 더보기 → 내 계정; 비밀번호 변경, 이메일 변경, 알림 센터, 계정 해지 |

기업 버전과의 차이:

- **「조직 및 멤버」 없음**: 부서, 멤버 개설, 부서 예산 등 관리 요구가 존재하지 않습니다;
- **티켓에 승인 단계 없음**: 생성한 번역 티켓이 바로 대기열에 들어가 실행되며, 「승인 대기」에 머무르지 않습니다;
- 기업 전용 서브 도메인과 조직 공유 지식베이스가 없습니다; 업종 패키지, 언어·문화 패키지 등 플랫폼 공통 지식베이스는 동일하게 자동 적용됩니다.

개인 버전 할당량 또는 잔액이 부족할 경우, 화면 안내에 따라 처리하시면 됩니다.

## 4. 실시간 번역 (워크스페이스)

「실시간 번역」은 로그인 후 기본 페이지로, 전체 화면 대화창 형태이며 이력은 위쪽, 입력창은 아래쪽에 고정됩니다.

### 4.1 입력 영역 (입력 카드 하단 도구 모음)

하나의 입력 카드 안에 한 줄 자동 확장 입력창과 한 줄의 도구 모음이 있습니다:

| 구성 요소 | 설명 |
|------|------|
| 원문·자동 감지 | 원본 언어 선택, 기본값 자동 감지 |
| 목표 언어 | 클릭하여 선택기 오픈; 언어군을 「지식베이스 언어 / 기타 언어 (AI 번역)」로 그룹화하고, 「기타 언어…」에서 전체 언어 검색 가능; 선택된 언어는 태그로 표시되고 3개 초과 시 「+n」으로 접히며, 클릭하면 개별 제거 가능 |
| 전문 교정 / 신속 | 번역 모드. 신속＝AI 초번+교정, 경량·고처리량; 전문 교정＝지식베이스 용어 교정 + 품질 평가 + 하드 검증 게이트 전체 플로우, 공식 발표에 적합 |
| 압축 번역 | 체크 시 번역문이 길이 제약에 수렴하여, 제목·버튼 문구 등 글자 수 제한이 있는 씬에 적합 |
| 번역 (주 버튼) | 번역 시작; 생성 중에는 「생성 중지」 클릭 가능 |

예상 소모량은 발송 전에 표시됩니다. 잔액 부족 또는 할당량 소진 시 화면에 알림이 표시되고 관리자 문의 안내가 나옵니다.

### 4.2 대화와 결과

- 원문과 번역문이 같은 말풍선 안에 상하로 표시되며, 번역문은 스트리밍 방식으로 단락별로 화면에 나타납니다.
- 각 번역문에 출처 방식을 표기합니다: **정확히 일치 / 유사 매칭 / 의미 유사**(지식베이스) 또는 **온라인 번역**(AI 생성); 지식베이스 용어와 일치하면 강조 표시됩니다.
- 말풍선 조작: 번역문 복사, 원문 보기; 계속 지침을 보내 AI의 어조·스타일 조정을 요청할 수 있으며 문맥이 유지됩니다.
- 번역 과정의 단계(용어 검색 → 기계 번역 → 용어 교정 → 번역 완료)가 화면에 단계별 안내로 표시됩니다.

### 4.3 세션 관리

대화창 상단에 다음을 제공합니다:

- **이 세션 메시지 검색**(단축키 Ctrl/⌘+K);
- **세션 기록 내보내기**(Markdown 파일);
- **대화 비우기**.

### 4.4 사용량 표시

화면의 소모량은 통일되게 「포인트」로 표시하고 「번역 가능 문장 수」로 환산합니다. 입력 영역 근처에 상시 표시: 잔액(포인트 ≈ 문장 수), 오늘 소모량, 부서 예산 진행률(부서에 속하고 예산이 있는 경우).

## 5. 번역 티켓 (문서 번역)

모든 **파일 번역**은 「번역 티켓」 페이지에서 시작하며, 전체 플로우를 따릅니다: 생성 → (기업 설정에 따라) 승인 → 번역 → 전달.

### 5.1 번역 작업 생성

「번역 작업 생성」을 클릭하고 「텍스트」 또는 「파일」 탭을 선택합니다:

- **텍스트**: 긴 텍스트를 붙여넣고 목표 언어와 모드를 선택한 뒤 바로 티켓을 생성합니다.
- **파일**: 하나 이상의 파일을 업로드하며, 한 번에 여러 목표 언어를 체크할 수 있습니다(산출물은 zip으로 패키징되어 다운로드).

주요 필드:

| 필드 | 설명 |
|------|------|
| 전달 방식 | **원본 서식 유지(기본)**: 원본 서식의 번역 파일 전달(레이아웃 복원), 순수 텍스트 .md 예비 산출물 부속; **텍스트만**: 본문 추출 후 번역, 번역문 .md 전달, 레이아웃은 보장하지 않음(레거시 doc/ppt/xls、odt/epub/rtf 등에 적합) |
| 모드 | 빠른 모드 (지식베이스 없음) / 전문 교정 |
| 목표 언어 | 복수 선택 가능 |
| 예상 소모 | 생성 전 「예상 소모 {cost} 문장 · 잔여 {balance} 문장」 표시 |

파일 형식 지원:

| 분류 | 형식 | 전달 |
|------|------|------|
| 서식 복원 가능 | docx、pptx、xlsx、pdf、txt、csv、md | 동일 형식 번역 파일 |
| 대조표 전달 | srt、vtt、json、yaml 등 | 원문/번역문 대조 xlsx |
| 텍스트만 지원 | doc、ppt、xls 레거시 형식 계열, odt/ods/odp, rtf, epub | 번역문 .md |

제한 및 설명:

- 단일 티켓의 파일 수량과 크기에는 상한이 있습니다; PDF가 40MB 또는 120페이지를 초과하면 부드럽게 거부하며 docx 변환 후 재시도를 안내합니다.
- 스캔본 PDF(순수 이미지)는 지원하지 않습니다; 이미지 내 텍스트는 제품 방침상 번역하지 않습니다.
- 레이아웃 재작성이 실패할 경우, 해당 파일은 자동으로 .md 전달로 강등되고 사이트 내 메시지로 알림이 전송되며, 티켓 전체가 실패하지는 않습니다.

### 5.2 티켓 상태 및 전환

「내 작업」 목록은 상태로 필터링할 수 있으며, 상태 의미는:

```
대기 중 → 번역 중 → 완료됨
승인 대기 → 승인됨 → 번역 중 …    (기업 승인 활성화 시)
        └→ 반려됨
진행 중인 어떤 상태 → 취소됨
```

- 진행 중에는 「취소」 클릭 가능; 종료된 건은 「삭제」할 수 있습니다.
- 귀사에서 승인을 활성화한 경우, 티켓은 먼저 「승인 대기」에 놓이고 부서 관리자/조직 관리자가 관리 콘솔 「피드백/승인」의 승인 데스크에서 승인(승인됨)하거나 반려(반려됨, 사유 부속)합니다.

### 5.3 진행률 확인 및 다운로드

티켓을 열면 「실행 진행률」 스텝바를 볼 수 있고, 단계는 다음과 같습니다: 파싱 추출 → 지식베이스 매칭 → AI 초번 → 전문 교정 → 하드 검증 → 문화 검사 → 파일 재작성 등(모드와 파일 형식에 따라 표시).

- 완료 후 「다운로드」를 클릭하면 번역문을 가져옵니다; 텍스트만 예비 산출물은 「번역 텍스트만 다운로드 (.md)」로 사용할 수 있습니다.
- 다국어/다파일 작업의 다운로드는 zip 패키지입니다.

### 5.4 품질 검사 보고서

전문 교정 모드의 완료된 티켓에는 「품질 검사 보고서」 블록이 있습니다: 전체 결론(품질 검사 통과 / 품질 검사 미통과 / 품질 검사 요주의), 기계 평가 점수(만점 100) 및 단락별 설명. 결과에 이의가 있으면 티켓 상세에서 「의견 피드백 제출」을 이용하세요. 관리자가 백엔드에서 확인하고 답변합니다.

### 5.5 대조 편집 연계

완료된 티켓은 원클릭으로 「대조 편집」에 진입하여 단락별로 심사할 수 있습니다. 다음 장 참조.

## 6. 대조 편집

「대조 편집」은 티켓 번역문에 대한 최종 인력 검수에 사용합니다:

1. 티켓 상세에서 이동하거나, 「대조 편집」 페이지에서 티켓 ID/티켓 번호로 「불러오기」;
2. 좌측은 원문, 우측은 번역문 단락별 대조, 지식베이스 용어는 원문 쪽에 강조 표시;
3. 단락별로: **승인** / **반려**(코멘트/반려 사유 작성) / 번역문 직접 수정 가능;
4. 「저장」을 클릭하여 인력 수정본을 보존합니다.

인력 확인된 고품질 문장 쌍은 번역 메모리의 양질 출처입니다—기업 지식베이스 관리자가 정리하여 가져올 수 있습니다(7장 참조).

## 7. 지식베이스 및 번역 메모리

지식베이스(KB)로 번역이 「당신의 기업을 이해하게」 합니다: 용어 통일, 확인된 번역문 재사용, 컴플라이언스 표현 고정.

### 7.1 4층 콘텐츠

| 층 | 내용 | 대표 용도 |
|----|------|----------|
| L1 용어 | 용어 대조(브랜드명, 제품명 고정 역법 포함) | 표현 강제 통일 |
| L2 번역 메모리 (TM) | 확인된 원문/번역문 문장 쌍 | 문장 전체 또는 부분 직접 재사용 |
| L3 안전 구문 | 금지어 / 치환 쌍 / 스탈 규범 | 언어·문화 하드 게이트 검증, 번역문에서 자동 차단 또는 치환 |
| L4 파편 | 산발적 표현, 문형 참고 | 유사 매칭의 예문 참고 |

번역 시 매칭 우선순위: 본 조직 체인의 부서 패키지(해당 부서→상위→루트, 근접 우선) ＞ 조직 패키지 ＞ 업종/언어·문화 패키지; 부서 간 공유 패키지는 관리자가 활성화해야 폴백 층으로 참여합니다.

### 7.2 누가 무엇을 유지보수하는가

| 작업 | 필요 역할 |
|------|----------|
| 상단 바 「지식베이스 업로드」(파일 인식 → 패키지 선택 → 가져오기) | 부서 관리자 이상 |
| **부서 패키지**, **부서 간 패키지** 생성/유지보수 | 부서 관리자 이상 |
| **조직 패키지(해당 기업)** 생성/유지보수, 부서 간 공유 총 스위치, 패키지 수준 권한 부여 | 조직 관리자 |
| 「브랜드명」(브랜드/제품 고정 역명) 유지보수 | 지식베이스 패널 접근 가능 역할 |
| 병렬 문장 / TMX 가져오기, TMX 내보내기 | 부서 관리자 이상 |
| 「언어/문화 규범 (안전 구문)」 유지보수 | 부서 관리자 이상 |

### 7.3 패키지 유형

- **테넌트 패키지 (해당 기업)**: 전 기업에 적용;
- **부서 패키지 (해당 부서)**: 해당 부서와 조직 체인 내에만 표시되어 부서 수준 용어 격리 실현;
- **부서 간 공유 패키지**: 기본 외부 대여 없음, 패키지 수준의 「부서 간 공유·켜기/끄기」+ 기업 정책 스위치가 함께 다른 부서 적용 여부를 결정합니다.

### 7.4 가져오기 방식

관리 콘솔 「지식베이스」 패널(부서 관리자 이상) 진입:

- **파일 가져오기**: 용어표/문서 업로드, 시스템 인식 후 선택 패키지에 기록;
- **병렬 문장 / TMX 가져오기**: 번역 메모리 일괄 기록, 주요 CAT 도구(Trados/memoQ 등)의 TMX 내보내기 호환;
- **TMX 내보내기**: 기업 메모리를 기존 도구 체인으로 회수합니다.

플랫폼 측은 업종별로 범용 「업종 패키지 / 언어·문화 패키지」를 자동 적용하며, 기업 유지보수 없이 번역 시 자동 적용됩니다.

### 7.5 내 직무 역할 (전원)

계정 메뉴 →「내 직무 역할」: 사전 역할 사전(15개 이상 직무)에서 본인 직무 역할을 선택합니다. 번역 시 시스템이 대응 역할 패키지를 자동 적용하여 용어와 어조를 당신의 업무 씬에 더 가깝게 맞춥니다.

## 9. 조직 및 멤버 관리 (조직 관리자)

진입구: 계정 메뉴 →「관리 콘솔로」→ 좌측 「조직 및 멤버」.

### 9.1 조직 구조

- **새 조직 / 새 부서**: 기업 다단계 조직 트리 유지보수; 이름 변경 지원.
- **부서 예산**: 부서에 「월간 예산 배정」을 하여 해당 부서 멤버의 번역 사용량을 통제; 멤버 화면에 부서 예산 진행률이 표시됩니다.

### 9.2 멤버 계정

「멤버 계정」 페이지에서 기업 전체 계정을 관리합니다:

- **사용자 추가**: 멤버 개별 생성, 역할(일반 사용자 / 부서 관리자 / 조직 관리자)과 소속 조직 지정;
- **일괄 가져오기 (Excel)**: 여러 멤버 한 번에 개설, 초기 비밀번호는 이메일 통지로 전달되며 멤버는 첫 로그인 시 비밀번호 변경을 요구받습니다;
- 기존 멤버에 대해: **비밀번호 재설정**, 계정 **활성화/비활성화**, 역할 및 조직 소속 조정.

### 9.3 직원 초대

「직원 초대」 페이지에서 **초대 코드**를 생성합니다(여러 개 가능, 가입할 조직 계층 지정 가능). 조직 코드 + 초대 코드를 동료에게 알려주면, 등록 페이지에서 입력하여 해당 부서에 가입합니다.

### 9.4 SCIM 조직 동기화 (선택)

「더보기 → 내 계정」의 SCIM 카드: 기업이 Okta、Entra ID 등 신원 공급자를 사용하는 경우, SCIM 엔드포인트와 토큰을 발급받아 멤버 자동 개설/동기화를 완료할 수 있습니다; 활성화 후 직원은 로그인 페이지의 SSO 단추로 비밀번호 없이 로그인할 수 있습니다.

## 10. 외부 호출 및 통합 (조직 관리자)

진입구: 관리 콘솔 →「외부 호출」. 세 개 하위 탭: **Open API**, **Webhook**, **공식 SDK**.

### 10.1 Open API Key

- **API Key 발급**: 생성 시 평문 전체 표시는 **단 한 번뿐**이므로 즉시 저장하세요;
- Key에 대해 **활성화/비활성화、회전、일일 상한 설정、삭제** 지원;
- Key는 본 기업 테넌트 및 포인트 기준에 바인딩되며, API로 발생한 소모량은 웹과 동일 장부에 반영됩니다.

Open API 제공 내용: 비동기 번역 작업(생성 → 폴링 → 다운로드, 다파일 다국어 지원, 산출물 zip 패키징 가능), 동기 단문 번역(≤5000자、≤5개 언어), 잔액 및 사용량 조회, 지식베이스 통계. 인터페이스 문서는 브라우저에서 사이트의 `/openapi/docs`에 접근하여 볼 수 있습니다.

### 10.2 Webhook 콜백

콜백 URL 등록 후 이벤트(예: `translation.completed`)를 구독하면, 번역 완료 시 플랫폼이 귀사 시스템으로 능동 통지; 서명 검증(X-Signature), 테스트 발송, 전송 이력 조회 및 재시도를 지원합니다.

### 10.3 공식 SDK 및 플러그인

「공식 SDK」 페이지에 3단 설치 안내와 다운로드 진입구가 있습니다:

| 디바이스 | 획득 방식 | 용도 |
|----|----------|------|
| Python | `pip install langcross-translator` | 프로그래밍식 번역, 일괄 작업 |
| TypeScript | `npm i @langcross/translator-sdk` | Node/프론트엔드 통합 |
| Java | Maven 소스 배포 | 기업 내 시스템 연동 |
| 브라우저 선택 번역 확장 | 해당 페이지에서 zip 다운로드(앱 스토어 채널 없음) | 임의 웹페이지에서 텍스트 선택 → 팝업 「译」 단추 클릭 → 말풍선으로 번역문 보고 복사; 단축키 Alt+Shift+T(macOS는 Alt+T) |
| Word 애드인 | 사이트가 제공한 애드인 매니페스트, Word 「삽입 → 애드인 가져오기 → 내 애드인 업로드」로 사이드로딩 | Word 내에서 선택 텍스트 번역 후 문서로 삽입 |
| VS Code 플러그인 | 저장소 내 vscode-extension | 에디터 내 선택 텍스트 즉시 번역, 용어 조회 |

**확장/애드인 설정**(선택 번역 팝업과 Word 창 패널 동일 로직): **서비스 주소**(사이트 루트 주소), **API Key**(본 장 10.1에서 발급), **목표 언어**, **번역 모드**(신속/전문 교정)만 입력하면 사용 가능하고, 용어와 번역 메모리는 사이트 내와 동일합니다.

⚠ 확장 업그레이드 후 스타일이 변하지 않았다면: 새 zip으로 **동일 디렉터리**를 덮어쓰고 `chrome://extensions`에서 해당 확장 카드의 **새로고침** 단추를 클릭하세요.

### 10.4 부서 관리자의 경계

부서 관리자에게 API 통합이 필요하면 조직 관리자께 Key 발급을 문의하세요; 「외부 호출」 메뉴는 부서 관리자에게 표시되지 않습니다.

## 11. 알림, 피드백 및 AI 어시스턴트

### 11.1 알림 센터 (전원)

상단 바 벨: 30초 단위 폴링으로 미읽은 알림 확인, 드롭다운에서 사이트 내 메시지(티켓 완료, 승인 결과, 전달 방식 강등 알림 등) 조회, 개별 또는 전체 읽음 표시 가능.

### 11.2 피드백 제출 및 처리

- **전원**: 완료된 티켓 상세에서 「의견 피드백 제출」로 문제 단락과 기대 사항을 설명합니다.
- **부서 관리자/조직 관리자**: 관리 콘솔 「피드백/승인」에서 본 테넌트 피드백을 확인하고 **답변**합니다; 같은 페이지의 「승인 데스크」에서 승인 대기 티켓을 처리(승인/반려)합니다.
- 「개요」 패널(부서 관리자 이상): 본 기업 운영 보드와 사용량 명세 조회(사용량은 CSV 내보내기 가능).

### 11.3 AI 어시스턴트 위젯 (전원 및 게스트)

페이지 우측 하단 「AI 어시스턴트」 단추로 언제든 대화 호출: 제품 문의, 기능 안내, 빠른 바로가기. 페이지를 새로고침해도 대화는 유지됩니다(로컬 캐시 → 클라우드 이력 자동 복원).

## 12. 자주 묻는 질문

**Q1: 번역 단추가 눌리지 않거나 / 할당량 부족 알림이 뜹니다?**
현재 잔액 또는 부서 예산이 모두 소진된 것입니다. 일반 사용자는 기업 관리자에게 문의하여 처리하시고; 관리자는 관리 콘솔에서 사용량 명세를 확인할 수 있습니다.

**Q2: 파일 번역 진입구는 어디인가요? 대화창에 첨부 파일을 올릴 수 없는데 왜요?**
파일 번역은 통일되게 「번역 티켓 → 파일」로 진행하며, 대화창은 순수 텍스트 번역만 합니다.

**Q3: PDF 번역이 거부되었습니다?**
PDF가 40MB 또는 120페이지를 초과하면 먼저 docx로 변환한 뒤 티켓을 생성하세요; 스캔본 PDF(전면 이미지)는 현재 지원하지 않습니다.

**Q4: 번역문이 제 용어표와 다른 이유는 무엇인가요?**
용어가 지식베이스에 가져오기되었고 패키지가 본 부서에 표시되는지 확인하세요(7장); 정식 발표 내용은 「전문 교정」 모드를 선택해 주세요.

**Q5: 전달된 docx의 레이아웃이 원문과 다소 다릅니다?**
「원본 서식 유지」는 대부분 경우 레이아웃을 보존합니다; 일부 복잡한 레이아웃은 .md 텍스트 전달로 강등되고 사이트 내 메시지로 알림합니다. .md를 다운로드한 뒤 대조 편집으로 심사하거나 피드백을 제출하세요.

**Q6: 번역이 방금 끝났는데 잔액 숫자가 그대로예요?**
측량은 번역 완료 순간 동기적으로 DB에 기록됩니다. 페이지가 갱신되지 않았다면 수동으로 새로고침하세요; 그래도 이상하면 피드백을 제출해 주세요.

**Q7: 폰/태블릿에서도 사용할 수 있나요?**
브라우저로 바로 접근하면 되고, 화면은 좁은 폭에 자동 대응합니다; 확장 및 애드인은 데스크톱 위주입니다.

**Q8: 화면 텍스트가 다 안 보이거나 조판이 이상합니다(아랍어 등)?**
먼저 다른 언어로 전환하여 개별 용어 문제인지 확인한 뒤, 피드백 채널로 스크린샷을 제출해 주세요.
