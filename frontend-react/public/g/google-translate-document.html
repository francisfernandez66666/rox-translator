Questions

What is the hidden cost of free document translation?

The hour after it: pasting sections back, fixing table widths, re-checking that one term means the same thing on page 3 and page 40.

Which formats come back as themselves?

PDF, DOCX, PPTX, XLSX, TXT, CSV and Markdown are rebuilt in place; subtitle and JSON-style files are delivered as an aligned bilingual table instead.

How do you keep a term identical across a whole set?

Knowledge package plus translation memory, applied before delivery. The decision is stored once, not renegotiated per file.

Does a failed layout write-back lose the content?

No. When write-back cannot be guaranteed the job still returns the complete translated text and flags the gap rather than reporting success.
