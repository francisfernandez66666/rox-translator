Questions

Why does a translated document need reassembly?

Because a DOCX is styles, numbering, headers and anchored tables. Translating the characters without touching that structure leaves you with a text file.

What decides whether layout survives?

How the pipeline treats the file: parsed as structure, or flattened into a text block and re-poured. Only the first one can keep a table where it was.

Can long documents keep terminology consistent?

Yes — a knowledge package applied before delivery plus translation memory, so a term does not change its mind halfway through a manual.

Is there a way to check without committing?

Send one real document through and open the result. Layout and terminology are both visible in the download; nothing here needs a demo script.
